## **1.1 Tipos de Análises**

- <span style="color:#b8bb26">**Análise Descritiva</span>:** é o exame de dados ou conteúdo, geralmente realizado manualmente, para responder à pergunta “<span style="color:#b8bb26">**O que aconteceu?**</span>” (ou O que está acontecendo?). Normalmente utiliza visualizações como gráficos de barras, gráficos de linha, tabelas.
- <span style="color:#d3869b">**Análise de Diagnóstico**</span>: é uma forma de análise avançada que examina dados ou conteúdo para responder à pergunta: “<span style="color:#d3869b">**Por que isso aconteceu?**</span>” Caracteriza-se por técnicas como detalhamento, mineração de dados e correlações.
- <span style="color:#83a598">**Análise Preditiva**:</span> é uma forma de análise avançada que examina dados ou conteúdo utilizada para prever cenários, respondendo à pergunta: “**<span style="color:#83a598">O que vai acontecer?</span>**”.
- **Análise <span style="color:#fe8019">Prescritiva**</span>: é uma forma de análise avançada que examina dados ou conteúdo para responder à pergunta “O<span style="color:#fe8019"> que deve ser feito</span>?” ou “**O que podemos fazer para fazer acontecer?**”, e é caracterizada por técnicas como análise de gráficos, simulação, processamento de eventos complexos e machine learning.

# **2. Business Intelligence**

A **inteligência de negócios**, ou **Business Intelligence**, é um conjunto de estratégias e ferramentas voltadas para a **análise de dados empresariais**. Essas práticas auxiliam na **tomada de decisões**, melhorando o desempenho e a competitividade das organizações.

Por meio do Business Intelligence, é possível transformar grandes volumes de dados brutos em **informações úteis e relevantes**. Isso permite identificar oportunidades, tendências e padrões, bem como prever e resolver problemas.

# **2.1 Componentes da Arquitetura BI**

- <mark style="background:rgba(240, 200, 0, 0.2)">**Data Warehouse**</mark>: banco ou repositório de dados preparado para dar suporte a aplicações de tomada de decisão;
- <mark style="background:rgba(163, 67, 31, 0.2)">**Análise de Negócios**</mark>: ferramentas para manipular, minerar e analisar dados, criar relatórios, etc;
- <mark style="background:rgba(136, 49, 204, 0.2)">**BPM**</mark>: conexão de métricas com desempenhos reais da organização;
- <mark style="background:rgba(140, 140, 140, 0.12)">**Interface de usuario**:</mark> visão rápida dos dados por meio de ferramentas de visualização.

# **3. Data Warehouse (armazém de dados)**

**O armazém de dados**, ou **Data Warehouse**, é um **repositório centralizado** onde informações de diferentes fontes são armazenadas e consolidadas. Essa estrutura facilita a análise e a extração de insights a partir dos dados coletados. Os Data Warehouses são projetados para lidar com dados históricos e atuais, permitindo uma visão ampla e detalhada dos negócios. Isso é crucial para o desenvolvimento de estratégias e aprimoramento dos processos empresariais.

## **3.1 Quatro Características Essenciais dos Data Warehouse** são:

- <mark style="background:rgba(3, 135, 102, 0.2)">**Integração**:</mark> consolidação de dados de **diversas fontes**;
- <mark style="background:rgba(92, 92, 92, 0.2)">**Não volatilidade**:</mark> os dados são armazenados de forma **permanente e imutável**;
- <mark style="background:rgba(240, 200, 0, 0.2)">**Orientado por assunto**:</mark> consiste em organizar os dados em torno de **temas específicos**;
- <mark style="background:rgba(140, 140, 140, 0.12)">**Variável no Tempo**</mark>: permite o armazenamento de **dados históricos** e **atuais** para análise e tomada de decisões.

## **3.2 Processo de Data Warehouse**

| DIVERSAS FONTE DE DADOS | ➡️  | ETL | ➡️  | DATA WAREHOUSE | ➡️  | APRESENTAÇÃO |
| ----------------------- | --- | --- | --- | -------------- | --- | ------------ |

Basicamente, o **processo de Data Warehousing** segue da seguinte forma:

- <span style="color:#b8bb26">Extração</span>: os **dados são coletados** de diferentes sistemas e fontes;
- <span style="color:#fb4934">Transformação</span>: os dados extraídos são **limpos, padronizados e enriquecidos**;
- <span style="color:#fe8019">Carregamento</span>: os dados transformados são **inseridos** no Data Warehouse;
- <span style="color:#83a598">Análise</span>: os dados armazenados são **analisados** para gerar insights e relatórios.
## **3.3 Abordagem Kimball vs. Inmon**

Existem duas abordagens principais no desenvolvimento de data warehouses:

**🔸 Abordagem Inmon**

- <mark style="background:rgba(3, 135, 102, 0.2)">Top-down</mark>: enfatiza a criação de um **modelo de dados corporativo unificado antes** de projetar as soluções específicas.

**🔸** **Abordagem Kimball**

- <mark style="background:rgba(140, 140, 140, 0.12)">Bottom-Up</mark>: concentra-se no desenvolvimento de soluções específicas e na **integração posterior** dessas soluções em um modelo de dados corporativo.

# **4. Processo de ETL**

- <span style="color:#b8bb26">Extração</span>: É o processo de **coletar e extrair dados** de diversas fontes heterogêneas, como sistemas operacionais, bancos de dados e arquivos.
- <span style="color:#fe8019">Transformação</span>: Envolve a **limpeza, padronização, enriquecimento** e aplicação de regras de negócio aos dados extraídos para garantir a qualidade e a consistência das informações.
- <span style="color:#fb4934">Carga</span>: Consiste em **inserir os dados transformados** no data warehouse ou em outro sistema de armazenamento de dados, permitindo que sejam utilizados para análises e geração de relatórios.

## **4.1 Pipeline de Dados (Diferenças)**


|                | Processamento de Fluxo                                              | Process</mark>amento em Lote                             |
| -------------- | ------------------------------------------------------------------- | -------------------------------------------------------- |
| **Frequência** | Executados **continuamente**                                        | Executados com **pouca frequencia**                      |
| **Computação** | Exiem **baixo** poder de computação                                 | Exigem **alto** poder de computação por um curto período |
| **Conexão**    | Precisam de conexões de **rede confiáveis** e de **baixa latência** | Executadas eralmente **fora dos horários de pico**       |
