# 1. Teoria da Informação (DIKW)
## 1.1 Dado

- Elementos <span style="color:#245bdb">brutos</span>, 
- **<span style="color:#245bdb">sem significado</span>**, 
- <span style="color:#245bdb">desvinculados da realidade</span>, 
- <span style="color:#245bdb">sozinhos não têm significado</span> 

## 1.2 Informação 

- A informação é a <span style="color:#92d050">ordenação e organização dos dados</span> de
forma que passa a transmitir uma mensagem compreensiva <span style="color:#92d050">dentro de um determinado contexto.</span>

## 1.3 Conhecimento

- Conhecimento é a <span style="color:#de7802">informação aplicada</span>
- Propriedade subjetiva, inerente a quem analisa os dados ou a informação
- Pode ser **<span style="color:#ff0000">explícito/tangível</span>** ou **<span style="color:#0070c0">intangível/tácito</span>**
	- <span style="color:#ff0000">Explícito/Tangível</span>: forma mais básica de conhecimento e facilidade de transmissão, uma vez que é geralmente <span style="color:#d83931">escrito e acessível</span>. 

	- <span style="color:#245bdb">Intangível/tácito</span>:  conhecimento que possuímos, obtido da <span style="color:#245bdb">experiência e do contexto pessoal.</span>

### 1.3.1 Espiral do Conhecimento

- Existem <u>quatro formas básicas</u> pelas quais o conhecimento pode ser <u>transmitido ou convertido.</u> Elas formam um conceito chamado de **<u><span style="color:#00b0f0">Espiral do Conhecimento</span></u>** (ou Modelo SECI):


| Formas de Transmissão | Descrição                                                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Socialização          | Interação do conhecimento através da troca de ideias e do compartilhamento de experiências, por meio de observação ou/e prática (Tácito para Tácito).   |
| Externalização        | O conhecimento pessoal passa para o domínio público por meio de uma documentação (Tácito para Explícito)                                                |
| Combinação            | Agrupamento do conhecimento explícito de<br>diferentes fontes, visando agregar valor para gerar um novo conhecimento (Explícito para Explícito).        |
| Internalização        | O conhecimento é adquirido por meio de alguma<br>publicação escrita que pode estar disponível em livro, revistas, Internet, etc (Explícito para Tácito) |

- Envolve a <span style="color:#ffc000">capacidade de julgamento</span> (essencialmente humano)

# 2. Dados Abertos

## 2.1 Definição
<p align="justify">Para que um dado seja considerado <u><span style="color:#d83931">aberto</span></u>,
ele deve reunir – no mínimo – as três características. No Brasil, este conceito é fundamental para a **[[5. Poderes e Deveres#1.2 Dever de prestar contas:|Lei de Acesso à Informação (LAI.md)]]**.</p>

| **Disponibilidade e Acesso**      | Devem estar <span style="color:#de7802">**disponíveis como um todo**</span> e sob <span style="color:#de7802"><span style="color:#de7802">custo não maior que um custo razoável de reprodução</span></span> |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Reutilização e Redistribuição** | Devem ser fornecidos sob termos que **<span style="color:#245bdb">permitam a combinação com outros conjuntos de dados não abertos                             </span>**                         |
| **Participação Universal**        | Todos devem ser capazes de <span style="color:#6425d0">usar, reutilizar e redistribuir                             </span>                                                                                                   |

## 2.2 Princípios


| **Completos**                  | Todos os dados públicos são <span style="color:#de7802">disponibilizados</span>.                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primários**                  | Publicados na <span style="color:#00b0f0">forma coletada na fonte</span>, com a mais fina granularidade possível, de forma não agregada ou transformada |
| **Atuais**                     | Disponibilizados o quão rapidamente seja necessário para preservar o seu valor                                                                    |
| **Acessíveis**                 | Disponibilizados para o <span style="color:#6425d0">público mais amplo possível</span> e para os propósitos mais variados possíveis                     |
| **Processáveis por Máquina**   | Razoavelmente estruturados para possibilitar o seu processamento automatizado                                                                     |
| **Acesso não Discriminatório** | <span style="color:#92d050">Disponíveis a todos                             </span>                                                                     |
| **Formatos não Propietários**  | Disponíveis em um formato sobre o qual nenhum ente tenha controle exclusivo                                                                       |
| **Livres de Licença**          | <span style="color:#de7802">Não estão sujeitos a regulações </span>de direitos autorais, marcas, patentes ou segredo industrial                         |

# 3. Metadados

## 3.1 Definição

- Dados sobre dados
- Utilizados para ajudar a descrever melhor os dados
- documentam e organizam os dados das organizações, com objetivo de minimizar duplicações de esforços e facilitar a manutenção de dados.

## 3.2 Classificações

### 3.2.1 Termos de Uso

- **<span style="color:#d83931">Técnicos</span>**: Descrição dos dados necessários para as diversas ferramentas que precisem **<span style="color:#d83931">armazenar, manipular ou movimentar</span>** dado
- **<span style="color:#245bdb">De Negócio</span>**: Descrição dados necessários pelos usuários de negócios, para **<span style="color:#245bdb">entender o contexto do negócio e o significado dos dados.</span>**

### 3.2.2 Padrões

- <span style="color:#d83931">Sintáticos</span>: Descrevem a <span style="color:#d83931">sintaxe</span> os dados
- <span style="color:#de7802">Estruturais</span>: Descrevem a <span style="color:#de7802">estrutura/organização</span> dos dados
- <span style="color:#245bdb">Semânticos</span>: Descrevem o <span style="color:#245bdb">significado/conteúdo</span> dos dados

### 3.2.3 Função 

- **<span style="color:#ffc000">Descritivos</span>**: Descrição de um **<span style="color:#ffc000">objeto</span>**
- **<span style="color:#92d050">Estruturais</span>**: Como um recurso é **<span style="color:#92d050">composto ou organizado</span>**
- **<span style="color:#0070c0">Administrativos</span>**: Fornecimento de informações que apoiam os **<span style="color:#0070c0">processos de gerenciamento</span>**

# 4. Dados Estruturados e Não Estruturados

## 4.1 Conceitos

- **<span style="color:#92d050">Estruturados</span>**: São dados **<span style="color:#92d050">bem definidos, relacionados, geralmente quantitativos</span>**, que demonstram claramente o que contém e são dispostos em blocos semânticos. Usualmente são **<span style="color:#92d050">organizados em uma estrutura fixa através de tabelas</span>**
- **<span style="color:#d83931">Não-Estruturados</span>**: São dados **<span style="color:#ff0000">geralmente qualitativos</span>** e usualmente **<span style="color:#ff0000">não possuem qualquer esquema</span>**, definição e relação entre eles, ou seja, são considerados arquivos de textos, relatórios textuais, músicas, imagens, vídeos, etc:
- **<span style="color:#245bdb">Semiestruturados</span>**: São dados estruturados que muitas vezes <span style="color:#0070c0">não estão de acordo com as estruturas definidas nos modelos relacionais, mas ainda assim possuem consistência e definição</span>, possuindo por vezes uma estrutura irregular e sem um esquema definido

# 5. Ciclo de Vida de Dados

## 5.1 Conceitos

Conjunto de etapas ou fases pelas quais um dado passa desde sua criação até o seu descarte. 

![[./Ciclo de Vida de Dados.png|]]

- **<span style="color:#de7802">Coleta</span>**: Dados podem ser utilizados para **<span style="color:#de7802">atender uma necessidade ou demanda específica</span>** sobre um determinado contexto.
- **<span style="color:#d83931">Tratamento</span>**: Responsável por <span style="color:#d83931">**transformar os dados** </span>de acordo com as regras de negócio. **<span style="color:#d83931">Tratar, transformar, processar, limpar, padronizar.</span>**
- **<span style="color:#d99694">Armazenamento</span>**: **<span style="color:#d99694">Armazenar</span>** os dados em uma base de dados
- <span style="color:#ffff00">**Integração**</span>: Ocorre desde a fase da coleta, busca integrar **<span style="color:#ffff00">dados de diferentes fontes</span>**
- <span style="color:#92d050">**Recuperação**</span>: Ampliação das **<span style="color:#92d050">possibilidades de acesso via cópia</span>** ou obtenção de conjuntos para análise.
- **<span style="color:#00b0f0">Descarte</span>**: **<span style="color:#00b0f0">Dados não mais necessários</span>**, são descartados

## 5.2 ETL

Processo mais crítico e demorado na construção de um Data Warehouse, uma vez que consiste na <span style="color:#de7802">extração</span> dos dados de fontes homogêneas ou heterogêneas; na <span style="color:#de7802">transformação</span> e <span style="color:#de7802">limpeza</span> destes dados; e na carga dos dados no DW.
