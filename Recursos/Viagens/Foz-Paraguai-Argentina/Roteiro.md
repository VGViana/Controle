# 🪪 Documentação

## Para os dois

### Brasil → Argentina/Paraguai

Para turismo no Mercosul:

- **CIN/RG em bom estado**, preferencialmente emitido há menos de 10 anos e com foto que permita identificação;
- ou **passaporte válido**.

### Não usar como documento de entrada

- CNH;
- carteira profissional;
- certidão;
- documentos similares.

A Polícia Federal confirma que, para turismo no Mercosul, a cédula de identidade é aceita nas condições acima.

# 🔐 Segurança

## Ciudad del Este

### Faça

- chegar cedo;
- andar com mochila fechada;
- guardar documentos em doleira/bolso interno;
- usar cartão quando vantajoso;
- carregar pouco dinheiro;
- conferir nota fiscal;
- testar eletrônicos quando possível;
- fotografar número de série;
- comparar lojas.

### Não faça

- aceitar “oferta especial” de desconhecido na rua;
- comprar eletrônico de vendedor informal;
- entregar cartão/documento para terceiros;
- comprar perfume/eletroeletrônico sem verificar procedência;
- sair mostrando o valor das compras.
