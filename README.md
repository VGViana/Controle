# 🏛️ Projeto Fisco: Constituição Naveável

## 🎯 Objetivo
Repositório centralizado de estudos para a área fiscal, estruturado para transformar o conteúdo programático em um sistema jurídico-tributário interconectado e de alta navegabilidade.

## 🏗️ Arquitetura do Vault
Este projeto segue a metodologia de **Constituição Naveável**, focada em:
- **MOCs (Maps of Content):** Notas de índice que servem como hubs centrais para cada disciplina.
- **Notas-Ponte:** Pontos de interseção interdisciplinares (ex: Direito Tributário ↔ Contabilidade).
- **Backlinks Semânticos:** Navegação contextualizada que reforça a memória de longo prazo e a visão sistêmica.

## 📚 Estrutura de Conteúdo
O repositório está organizado nos seguintes módulos principais:
- `00` - Painel Geral Fiscal (Hub Central)
- `01` - Direito Tributário
- `02` - Direito Constitucional
- `03` - Direito Administrativo
- `04/05` - Contabilidade (Geral e Avançada)
- `06` - Auditoria
- `07` - Legislação Tributária
- `08/09/10` - Base (Português, RLM, TI)
- `11/12` - Direito Civil e Empresarial
- `99` - Conceitos Gerais e Transversais

## 🛠️ Ferramental (Stack)
- **Obsidian:** Interface para visualização de grafos e gestão de conexões.
- **Neovim (LazyVim):** Engine de edição de alta performance para Markdown.
- **Git/GitHub:** Versionamento e sincronização segura entre dispositivos.

## ⌨️ Workflow de Estudo (Nvim)
Breve resumo dos comandos essenciais configurados para este vault:
- `<leader>ff`: Procurar notas rapidamente.
- `<leader>fg`: Busca global de termos e conceitos.
- `gd`: Pular para a definição/origem de um conceito.
- `Shift + l/h`: Navegação rápida entre notas abertas.
