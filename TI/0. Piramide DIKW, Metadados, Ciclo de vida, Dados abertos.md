# 1. Teoria da Informação (DIKW)

## 1.1 Dado

- Elementos <font color="#245bdb">brutos</font>, 
- **<font color="#245bdb">sem significado</font>**, 
- <font color="#245bdb">desvinculados da realidade</font>, 
- <font color="#245bdb">sozinhos não têm significado</font> 

## 1.2 Informação 

- A informação é a <font color="#92d050">ordenação e organização dos dados</font> de
forma que passa a transmitir uma mensagem compreensiva <font color="#92d050">dentro de um determinado contexto.</font>

## 1.3 Conhecimento

- Conhecimento é a <font color="#de7802">informação aplicada</font>
- Propriedade subjetiva, inerente a quem analisa os dados ou a informação
- Pode ser **<font color="#ff0000">explícito/tangível</font>** ou **<font color="#0070c0">intangível/tácito</font>**
	- <font color="#ff0000">Explícito/Tangível</font>: forma mais básica de conhecimento e facilidade de transmissão, uma vez que é geralmente <font color="#d83931">escrito e acessível</font>. 

	- <font color="#245bdb">Intangível/tácito</font>:  conhecimento que possuímos, obtido da <font color="#245bdb">experiência e do contexto pessoal.</font>

### 1.3.1 Espiral do Conhecimento

- Existem <u>quatro formas básicas</u> pelas quais o conhecimento pode ser <u>transmitido ou convertido.</u> Elas formam um conceito chamado de **<u><font color="#00b0f0">Espiral do Conhecimento</font></u>** (ou Modelo SECI):


| Formas de Transmissão | Descrição                                                                                                                                               |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Socialização          | Interação do conhecimento através da troca de ideias e do compartilhamento de experiências, por meio de observação ou/e prática (Tácito para Tácito).   |
| Externalização        | O conhecimento pessoal passa para o domínio público por meio de uma documentação (Tácito para Explícito)                                                |
| Combinação            | Agrupamento do conhecimento explícito de<br>diferentes fontes, visando agregar valor para gerar um novo conhecimento (Explícito para Explícito).        |
| Internalização        | O conhecimento é adquirido por meio de alguma<br>publicação escrita que pode estar disponível em livro, revistas, Internet, etc (Explícito para Tácito) |

## 1.4 Inteligência

- Quando se usa o <font color="#ffc000">conhecimento para algum propósito</font>
- Envolve a <font color="#ffc000">capacidade de julgamento</font> (essencialmente humano)

# 2. Dados Abertos

## 2.1 Definição
<p align="justify">Para que um dado seja considerado <u><font color="#d83931">aberto</font></u>,
ele deve reunir – no mínimo – as três características</p>

| **Disponibilidade e Acesso**      | Devem estar <font color="#de7802">**disponíveis como um todo**</font> e sob <font color="#de7802"><font color="#de7802">custo não maior que um custo razoável de reprodução</font></font> |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Reutilização e Redistribuição** | Devem ser fornecidos sob termos que **<font color="#245bdb">permitam a combinação com outros conjuntos de dados não abertos                             </font>**                         |
| **Participação Universal**        | Todos devem ser capazes de <font color="#6425d0">usar, reutilizar e redistribuir                             </font>                                                                                                   |

## 2.2 Princípios


| **Completos**                  | Todos os dados públicos são <font color="#de7802">disponibilizados</font>. <br>Dados públicos são dados que <font color="#ff0000">não estão sujeitos a limitações válidas de privacidade, segurança ou controle de acesso, reguladas por estatutos</font>. |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primários**                  | Publicados na <font color="#00b0f0">forma coletada na fonte</font>, com a mais fina granularidade possível, de forma não agregada                                                                                                                          |
| **Atuais**                     | Disponibilizados o quão rapidamente seja necessário para preservar o seu valor                                                                                                                                                                             |
| **Acessíveis**                 | Disponibilizados para o <font color="#6425d0">público mais amplo possível</font> e para os propósitos mais variados possíveis                                                                                                                              |
| **Processáveis por Máquina**   | Estruturados para possibilitar o seu processamento automatizado                                                                                                                                                                                            |
| **Acesso não Discriminatório** | <font color="#92d050">Disponíveis a todos                             </font>                                                                                                                                                                                                           |
| **Formatos não Propietários**  | Disponíveis em um formato sobre o qual nenhum ente tenha controle exclusivo                                                                                                                                                                                |
| **Livres de Licença**          | <font color="#de7802">Não estão sujeitos a regulações </font>de direitos autorais, marcas, patentes ou segredo industrial                                                                                                                                  |

# 3. Metadados

## 3.1 Definição

- Dados sobre dados
- Utilizados para ajudar a descrever melhor os dados
- documentam e organizam os dados das organizações, com objetivo de minimizar duplicações de esforços e facilitar a manutenção de dados.

## 3.2 Classificações

### 3.2.1 Termos de Uso

- **<font color="#d83931">Técnicos</font>**: Descrição dos dados necessários para as diversas ferramentas que precisem **<font color="#d83931">armazenar, manipular ou movimentar</font>** dado
- **<font color="#245bdb">De Negócio</font>**: Descrição dados necessários pelos usuários de negócios, para **<font color="#245bdb">entender o contexto do negócio e o significado dos dados.</font>**

### 3.2.2 Padrões

- <font color="#d83931">Sintáticos</font>: Descrevem a <font color="#d83931">sintaxe</font> os dados
- <font color="#de7802">Estruturais</font>: Descrevem a <font color="#de7802">estrutura/organização</font> dos dados
- <font color="#245bdb">Semânticos</font>: Descrevem o <font color="#245bdb">significado/conteúdo</font> dos dados

### 3.2.3 Função 

- **<font color="#ffc000">Descritivos</font>**: Descrição de um **<font color="#ffc000">objeto</font>**
- **<font color="#92d050">Estruturais</font>**: Como um recurso é **<font color="#92d050">composto ou organizado</font>**
- **<font color="#0070c0">Administrativos</font>**: Fornecimento de informações que apoiam os **<font color="#0070c0">processos de gerenciamento</font>**

# 4. Dados Estruturados e Não Estruturados

## 4.1 Conceitos

- **<font color="#92d050">Estruturados</font>**: Organizados e representados em uma **<font color="#92d050">estrutura rígida formal (modelo relacional)</font>**
- **<font color="#d83931">Não-Estruturados</font>**: Não possuem estrutura padronizada, sendo totalmente **<font color="#d83931">flexível e dinâmica</font>**
- **Semiestruturados**: Combinam ambos
