# 1. Dado, Informação, Conhecimento e Inteligência (DIKW)

## 1.1 Dado

- Elementos <font color="#245bdb">brutos</font>, 
- **sem significado**, 
- desvinculados da realidade, 
- sozinhos não têm significado 

## 1.2 Informação 

- A informação é a ordenação e organização dos dados de
forma que passa a transmitir uma mensagem compreensiva dentro de um determinado contexto.

## 1.3 Conhecimento

- Conhecimento é a informação aplicada
- Propriedade subjetiva, inerente a quem analisa os dados ou a informação
- Pode ser explícito ou intangível
