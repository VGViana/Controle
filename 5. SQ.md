# **2. DDL (_Data Definition Language_)**

## **2.1 CREATE TABLE**

O `CREATE TABLE` comando cria uma nova tabela no banco de dados.

**Exemplo:**

**<span style="color:#83a598">CREATE** **TABLE**</span> Gurujas(  
  
   CPF int,  
  
   UltimoNome varchar(255),  
  
   PrimeiroNome varchar(255),  
  
   Endereco varchar(255),  
  
   Cidade varchar(255)  
  
);
