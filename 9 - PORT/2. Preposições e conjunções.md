# **1. PREPOSIÇÕES**

É uma classe de palavras que **<span style="color:#b8bb26">estabelece relações entre termos</span>** de uma frase, indicando relação de lugar, tempo, modo, causa, finalidade, instrumento, companhia, dentre outras.

Preposição é sempre **<span style="color:#fb4934">invariável</span>,** ou seja, não se flexiona.

## **1.1. CLASSIFICAÇÃO**

### 1.1.1 As preposições podem ser **essenciais** ou **acidentais.**

|                            |                                                                                                        |                                                                                                                                   |
| -------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **Preposições essenciais** | **São aquelas que, na origem, funcionam como preposição**                                              | **a, ante, até, após, com, contra, de, desde, em, entre, para, per, perante, por, sem, sob, sobre, trás**                         |
| **Preposições acidentais** | São palavras que **pertencem a outra classe gramatical**, mas que podem atuar também como preposições. | como (= na qualidade de), conforme (= de acordo com), segundo (= conforme), consoante (= conforme), durante, que, menos, afora... |

### 1.1.2 As preposições podem ser **relacionais** ou **nocionais.** 

|                 |                                                                                                                                                                                |                                                                                                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Relacionais** | São exigidas por **verbos ou por nomes.** Assim, o valor delas é essencialmente gramatical.                                                                                    | **Ex**.: Preciso **de** bons conselhos. (Quem precisa precisa DE alguma coisa. A preposição é exigência do verbo).<br><br>**Ex**.: Tenho medo **de** palhaço. (Quem tem medo tem medo DE algo. A preposição é exigência do nome). |
| **Nocionais**   | Não são exigência de verbo nem de nome, mas surgem para **estabelecer uma noção, uma relação de sentido, podendo trazer noção de causa, instrumento, matéria, modo, posse...** | **Ex.:** Ela morreu **de** amor. (traz ideia de causa, de razão, de motivo).<br><br>**Ex**.: Essa casa é **de** Angélica. (traz ideia de posse)                                                                                   |

## **1.4 LOCUÇÃO PREPOSITIVA:**

Nada mais é do que **<span style="color:#b8bb26">mais de uma palavra</span>** indicando preposição. 

**Veja:** 

|                                             |                         |
| ------------------------------------------- | ----------------------- |
| Conversamos **sobre** Língua Portuguesa     | **preposição**          |
| Conversamos **acerca de** Língua Portuguesa | **locução prepositiva** |

Alguns exemplos de **locuções prepositivas**: 

|                            |                |
| -------------------------- | -------------- |
| **embaixo de = sob**       | **lugar**      |
| **a fim de = para**        | **finalidade** |
| **dentro de = em**         | **lugar**      |
| **de encontro a = contra** | **posição**    |
| **acerca de = sobre**      | **assunto**    |
| **devido a = com**         | **causa**      |
| **a respeito de = sobre**  | **assunto**    |

# **2. CONJUNÇÕES**

É uma classe de palavras que tem a função de **<span style="color:#b8bb26">conectar</span> palavras** e **frases.** Ligam **orações** ou **palavras de mesma função sintática**.

São usadas para **expressar relações entre ideias**, como: adição, contraste, causa, consequência, finalidade, modo, explicação, alternância e conclusão. 

Os tipos de conjunções são: **<span style="color:#b8bb26">coordenativas</span>** e **<span style="color:#b8bb26">subordinativas</span>.**

## **2.1 CONJUNÇÕES COORDENATIVAS:**

Elas conectam palavras, frases ou orações **<u>independentes</u>** que têm a mesma função gramatical.

Existem **<span style="color:#b8bb26">cinco</span>** tipos de conjunções coordenativas:

| Tipo             | Definição                                                              | Exemplos                                                                                                        |
| ---------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **Aditivas**     | expressam **adição**                                                   | **Ex.:** e, também, além disso, bem como, ademais, não só, mas também.                                          |
| **Adversativas** | possuem ideia de **contraste ou oposição**                             | **Ex**.: mas, porém, contudo, todavia, entretanto, no entanto.                                                  |
| **Alternativas** | indicam **escolha ou alternância**                                     | **Ex**.: ou... ou, quer... quer, seja... seja, ora... ora.                                                      |
| **Conclusivas**  | Ligam orações ou palavras com sentido de **conclusão ou consequência** | **Ex**.: logo, portanto, então,<br><br>por isso, assim, por conseguinte, destarte, pois (quando vem deslocado). |
| **Explicativas** | Ligam orações ou palavras com sentido de **justificativa, explicação** | **Ex**.: que, porque, pois (se vier no<br><br>início da oração), porquanto                                      |

- A conjunção "mas" pode assumir dois valores principais: o valor contrastivo e o valor opositivo. A diferença entre eles está no tipo de relação que se estabelece entre as ideias conectadas.
	- Valor contrastivo: estabelece uma diferença ou contrariedade entre duas ideias, mas não necessariamente uma negação ou exclusão de uma pela outra.
	- Valor opositivo: cria uma oposição direta e excludente, em que uma ideia corrige, refuta ou invalida a anterior.
## **2.1 CONJUNÇÕES COORDENATIVAS:**

Elas conectam palavras, frases ou orações **<span style="color:#b8bb26"><u>independentes</u></span>** que têm a mesma função gramatical. Existem diferentes tipos de conjunções coordenativas:

| **Tipo**         | **Função**                               | **Exemplos**                                                          |
| ---------------- | ---------------------------------------- | --------------------------------------------------------------------- |
| **Aditivas**     | Expressam adição.                        | e, também, além disso, bem como, não só... mas também                 |
| **Adversativas** | Expressam contraste ou oposição.         | mas, porém, contudo, todavia, entretanto, no entanto                  |
| **Alternativas** | Indicam escolha ou alternância.          | ou... ou, quer... quer, seja... seja, ora... ora                      |
| **Explicativas** | Introduzem explicação ou esclarecimento. | porque, que, porquanto, isto é, pois (antes do verbo)                 |
| **Conclusivas**  | Expressam conclusão ou fechamento.       | por isso, logo, portanto, assim, por conseguinte, pois (após o verbo) |
## **2.2 CONJUNÇÕES SUBORDINATIVAS:**

São aquelas que introduzem uma **<span style="color:#b8bb26">oração subordinada</span>**, que **depende de uma oração principal** para completar seu sentido. Assim, estabelecem uma relação de **<u>subordinação</u>** entre as duas orações.

### **2.2.1 CLASSIFICAÇÃO**

Podem ser **<span style="color:#b8bb26">integrantes</span>** ou **<span style="color:#b8bb26">adverbiais</span>.**

#### **2.2.1.1 INTEGRANTES:**

Como o próprio nome diz, **integram,** **completam** o sentido da oração principal. Introduzem orações substantivas (aquelas que podem ser substituídas por **<span style="color:#fb4934">ISSO</span>.**

É importante **que** você estude = É importante **<span style="color:#fb4934">ISSO</span>**). As duas mais comuns são: **<span style="color:#b8bb26">QUE</span>** e **<span style="color:#b8bb26">SE</span>.**

**Ex.:**

|                                  |                                 |
| -------------------------------- | ------------------------------- |
| A verdade é **que** eu amo você. | Não sei **se** você está feliz. |

#### **2.2.1.2 ADVERBIAIS:**

Introduzem **<u>orações subordinadas adverbiais</u>**. Podem indicar:

| **Tipo**          | **Função**                         | **Exemplos**                                      |
| ----------------- | ---------------------------------- | ------------------------------------------------- |
| **Condicionais**  | Indicam hipótese ou condição.      | se, caso, desde que, contanto que, a menos que    |
| **Conformativas** | Indicam conformidade ou modo.      | conforme, segundo, consoante, como                |
| **Finais**        | Indicam finalidade ou propósito.   | a fim de que, para que, de modo que, de sorte que |
| **Proporcionais** | Indicam proporção.                 | à proporção que, à medida que, quanto mais        |
| **Temporais**     | Indicam tempo.                     | quando, enquanto, assim que, logo que, até que    |
| **Comparativas**  | Indicam comparação.                | como, assim como, mais que, menos que, tão quanto |
| **Causais**       | Indicam causa ou motivo.           | porque, pois, já que, visto que, porquanto        |
| **Consecutivas**  | Indicam consequência ou resultado. | de modo que, de sorte que, tão que, tanto que     |
| **Concessivas**   | Indicam concessão ou adversidade.  | embora, ainda que, mesmo que, por mais que        |

##### **2.2.1.2.1 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS CONDICIONAIS**

Trazem verbo com ideia de **<span style="color:#b8bb26">hipótese, condição, possibilidade.</span>**

Algumas conjunções **condicionais:**

|                   |
| ----------------- |
| **Se**            |
| **Caso**          |
| **Desde que**     |
| **Contando que**  |
| **Salvo se**      |
| **A não ser que** |
| **A menos que**   |
| **Sem que**       |

**Ex.:**

|                                                         |
| ------------------------------------------------------- |
| **Se** você estudar muito, será aprovado.               |
| **Caso** você saia hoje, leve o guarda-chuva.           |
| **Desde que** fale baixo, poderá permanecer na reunião. |

##### **2.2.1.2.2 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS CONFORMATIVAS**

Introduzem uma oração com ideia de **<span style="color:#b8bb26">conformidade</span>,** indicando a maneira ou o modo como se realiza a ação da oração principal. Expressam a ideia de conformidade, de **concordância** em relação à ação principal. 

Algumas conjunções **conformativas:**

|               |
| ------------- |
| **Conforme**  |
| **Segundo**   |
| **Consoante** |
| **Como**      |

**Ex.:**

|                                                                              |
| ---------------------------------------------------------------------------- |
| **Conforme** a Constituição Federal de 1988, o direito à vida é fundamental. |
| **Segundo** o filósofo, a liberdade encontra limites.                        |
| **Como** mostra o estudo, o índice de desemprego aumentou nos últimos anos.  |

##### **2.2.1.2.3 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS FINAIS**

Introduzem ideia de **<span style="color:#b8bb26">finalidade</span>,** de **<span style="color:#b8bb26">propósito</span>,** de **<span style="color:#b8bb26">objetivo</span>** da ação expressa na oração principal.  

Algumas conjunções **finais:**

|                  |
| ---------------- |
| **A fim de que** |
| **Para que**     |
| **De modo que**  |
| **De sorte que** |

**Ex.:**

|                                                                                          |
| ---------------------------------------------------------------------------------------- |
| Estamos estudando muito **para que** sejamos aprovados no concurso.                      |
| Ele trabalha muito **a fim de que** sua família tenha conforto.                          |
| As páginas estão numeradas **de modo que** seja fácil encontrar a documentação desejada. |

##### **2.2.1.2.4 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS PROPORCIONAIS**

Indicam uma relação de proporção entre a ação da oração principal e da oração subordinada. Expressam como uma ação está relacionada a outra em termos de **<span style="color:#b8bb26">proporção</span>,** **<span style="color:#b8bb26">quantidade</span>** ou **<span style="color:#b8bb26">intensidade</span>.** 

Algumas conjunções **proporcionais:**

|                     |
| ------------------- |
| **À proporção que** |
| **À medida que**    |
| **Ao passo que**    |
| **Quanto mais**     |
| **Quanto menos**    |

**Ex.:**

|                                                        |
| ------------------------------------------------------ |
| **À proporção que** estudo, adquiro conhecimento.      |
| **À medida que** ele treinava, melhorava o desempenho. |
| **Quanto mais** ele comia, **mais** engordava.         |

##### **2.2.1.2.5 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS TEMPORAIS**

Introduzem uma oração temporal, indicando o **<span style="color:#b8bb26">tempo</span>** em que ocorre a ação. 

Algumas conjunções **temporais:**

|                                   |
| --------------------------------- |
| **Quando**                        |
| **Enquanto**                      |
| **Sempre que**                    |
| **Toda vez que**                  |
| **Cada vez que**                  |
| **Assim que**                     |
| **Logo que**                      |
| **Mal (no sentido de assim que)** |
| **Depois que**                    |
| **Até que**                       |
| **Antes que**                     |

**Ex.:**

|                                                         |
| ------------------------------------------------------- |
| **Mal** saiu de casa, o telefone tocou.                 |
| **Depois que** encontrei você, descobri o que é o amor. |
| Permaneci calada **até que** o juiz me deu a palavra.   |

##### **2.2.1.2.6 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS COMPARATIVAS**

Introduzem uma oração com ideia de **<span style="color:#b8bb26">comparação</span>** entre duas ações.

Algumas conjunções **comparativas:**

|                  |
| ---------------- |
| **Como**         |
| **Assim como**   |
| **Bem como**     |
| **Mais que**     |
| **Menos que**    |
| **Melhor que**   |
| **Pior que**     |
| **Tal qual**     |
| **Tal como**     |
| **Tal quanto**   |
| **Tanto quanto** |

**Ex.:**

|   |
|---|
|Falava **como** se não precisasse dar explicações.|
|Estou **mais** calma **que** ele.|
|Esse lugar é **tão** frio **quanto** o outro.|

##### **2.2.1.7 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS CAUSAIS**

Introduzem ideia de **<span style="color:#b8bb26">causa</span>,** de **<span style="color:#b8bb26">motivo</span>,** de **<span style="color:#b8bb26">razão</span>** da ação expressa na oração principal.

Algumas conjunções **causais:**

|                      |
| -------------------- |
| **Porque**           |
| **Pois**             |
| **Na medida em que** |
| **Uma vez que**      |
| **Já que**           |
| **Visto que**        |
| **Por isso que**     |
| **Que**              |
| **Porquanto**        |

**Ex.:**

|                                                                 |
| --------------------------------------------------------------- |
| **Porquanto** estamos ocupados, ninguém veio falou conosco.     |
| Não vou sair agora, **já que** está chovendo muito.             |
| **Uma vez que** terminou o dever de casa, foi correndo brincar. |

**<span style="color:#fb4934">Obs.:</span>**

**À medida que** é locução conjuntiva com ideia de **proporção**.

Já **na medida em que** tem ideia de **explicação**, de **causa**.

##### **2.2.1.8 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS CONSECUTIVAS**

Indicam uma relação de **<span style="color:#b8bb26">consequência</span>** ou **<span style="color:#b8bb26">resultado</span>** da ação expressa na oração principal.

Algumas conjunções **consecutivas:**

|                    |
| ------------------ |
| **De modo que**    |
| **De sorte que**   |
| **De forma que**   |
| **De maneira que** |
| **Tal que**        |
| **Tão que**        |
| **Tanto que**      |

**Ex.:**

|                                                                   |
| ----------------------------------------------------------------- |
| Estava **tão** cansado **que** mal conseguiu levantar.            |
| O problema foi resolvido **de modo que** ninguém foi prejudicado. |
| Estudei **tanto que** fiquei com dor de cabeça.                   |

##### **2.2.1.9 CONJUNÇÕES SUBORDINATIVAS ADVERBIAIS CONCESSIVAS**

Indicam uma **<span style="color:#b8bb26">concessão</span>,** uma ideia contrária ou uma circunstância **<span style="color:#b8bb26">adversa</span>** em relação à ação expressa na oração principal. 

Algumas conjunções **concessivas:**

|                   |
| ----------------- |
| **Embora**        |
| **Conquanto**     |
| **Ainda que**     |
| **Mesmo que**     |
| **Por mais que**  |
| **Apesar de que** |

**Ex.:**

|                                                                               |
| ----------------------------------------------------------------------------- |
| **Embora** tivesse dificuldades, não desistiu.                                |
| **Ainda que** eu não concorde, respeitarei seu posicionamento.                |
| **Por mais que** a vida seja difícil, vale a pena acreditar em dias melhores. |

**<span style="color:#fb4934">Obs.:</span>**

Após conjunção ou locução conjuntiva concessiva, o verbo vai para o modo subjuntivo.

**Ex.:** 

**Embora eu faça / Ainda que eu estude / Por mais que eu tente.**

### **2.2.2 CONJUNÇÕES COM MAIS DE UM VALOR:**

**<span style="color:#b8bb26">Desde que:</span>**

|              |                                                                               |
| ------------ | ----------------------------------------------------------------------------- |
| **Tempo**    | **Ex.: Desde que** nos vimos pela primeira vez, nunca mais ficamos separados. |
| **Condição** | **Ex**.: **Desde que** você termine de lavar a louça, poderá brincar.         |

**<span style="color:#b8bb26">Porque:</span>**

|                        |                                                               |
| ---------------------- | ------------------------------------------------------------- |
| **Explicação / Causa** | **Ex.**: Estudo **porque** quero ser aprovado.                |
| **Finalidade**         | **Ex**.: Estudo **porque (= para que)** consiga ser aprovado. |

**<span style="color:#b8bb26">E:</span>**

|                 |                                                                  |
| --------------- | ---------------------------------------------------------------- |
| **Adição**      | **Ex.:** Conversamos **e** rimos bastante**.**                   |
| **Adversidade** | **Ex**.: Tentei argumentar, **e** de nada adiantou.              |
| **Conclusão**   | **Ex**.: Treinei para a maratona **e** fiquei em primeiro lugar. |

**<span style="color:#b8bb26">Como:</span>**

|                  |                                                                   |
| ---------------- | ----------------------------------------------------------------- |
| **Comparação**   | **Ex.:** Estou animada **como** se estivesse de férias.           |
| **Conformidade** | **Ex**.: **Como** expliquei, não posso sair de casa hoje.         |
| **Causa**        | **Ex**.: **Como** você não me falou nada, não trouxe o documento. |

**<span style="color:#b8bb26">Pois:</span>**

|                |                                                                             |
| -------------- | --------------------------------------------------------------------------- |
| **Causa**      | **Ex.:** Estamos molhados, **pois** estava chovendo.                        |
| **Explicação** | **Ex**.: Viajamos pela manhã **porque** não queríamos enfrentar o trânsito. |
| **Conclusão**  | **Ex**.: Estudou muito, passou, **pois**, dentro das vagas.                 |
