# **1. PREPOSIÇÕES**

É uma classe de palavras que **<span style="color:#b8bb26">estabelece relações entre termos</span>** de uma frase, indicando relação de lugar, tempo, modo, causa, finalidade, instrumento, companhia, dentre outras.

Preposição é sempre **<span style="color:#fb4934">invariável</span>,** ou seja, não se flexiona.

## **1.1. CLASSIFICAÇÃO**

### 1.1.1 As preposições podem ser **essenciais** ou **acidentais.**

|                                        |                                                                                                        |                                                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| **Preposições essenciais**             | **São aquelas que, na origem, funcionam como preposição**                                              | **a, ante, até, após, com, contra, de, desde, em, entre, para, per, perante, por, sem, sob, sobre, trás**                         |
| **  <br>  <br>Preposições acidentais** | São palavras que **pertencem a outra classe gramatical**, mas que podem atuar também como preposições. | como (= na qualidade de), conforme (= de acordo com), segundo (= conforme), consoante (= conforme), durante, que, menos, afora... |

### 1.1.2 As preposições podem ser **relacionais** ou **nocionais.** 

|                                         |                                                                                                                                                                                |                                                                                                                                                                                                                                   |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **  <br>  <br>  <br>  <br>Relacionais** | São exigidas por **verbos ou por nomes.** Assim, o valor delas é essencialmente gramatical.                                                                                    | **Ex**.: Preciso **de** bons conselhos. (Quem precisa precisa DE alguma coisa. A preposição é exigência do verbo).<br><br>**Ex**.: Tenho medo **de** palhaço. (Quem tem medo tem medo DE algo. A preposição é exigência do nome). |
| **  <br>  <br>  <br>Nocionais**         | Não são exigência de verbo nem de nome, mas surgem para **estabelecer uma noção, uma relação de sentido, podendo trazer noção de causa, instrumento, matéria, modo, posse...** | **Ex.:** Ela morreu **de** amor. (traz ideia de causa, de razão, de motivo).<br><br>**Ex**.: Essa casa é **de** Angélica. (traz ideia de posse)                                                                                   |

## **1.4 LOCUÇÃO PREPOSITIVA:**

Nada mais é do que **<span style="color:#b8bb26">mais de uma palavra</span>** indicando preposição. 

**Veja:** 

|                                             |                         |
| ------------------------------------------- | ----------------------- |
| Conversamos **sobre** Língua Portuguesa     | **preposição**          |
| Conversamos **acerca de** Língua Portuguesa | **locução prepositiva** |

Alguns exemplos de **locuções prepositivas**: 

|   |   |
|---|---|
|**embaixo de = sob**|**lugar**|
|**a fim de = para**|**finalidade**|
|**dentro de = em**|**lugar**|
|**de encontro a = contra**|**posição**|
|**acerca de = sobre**|**assunto**|
|**devido a = com**|**causa**|
|**a respeito de = sobre**|**assunto**|

# **2. CONJUNÇÕES**

É uma classe de palavras que tem a função de **<span style="color:#b8bb26">conectar</span> palavras** e **frases.** Ligam **orações** ou **palavras de mesma função sintática**.

São usadas para **expressar relações entre ideias**, como: adição, contraste, causa, consequência, finalidade, modo, explicação, alternância e conclusão. 

Os tipos de conjunções são: **<span style="color:#b8bb26">coordenativas</span>** e **<span style="color:#b8bb26">subordinativas</span>.**

## **2.1 CONJUNÇÕES COORDENATIVAS:**

Elas conectam palavras, frases ou orações **<u>independentes</u>** que têm a mesma função gramatical.

Existem **<span style="color:#b8bb26">cinco</span>** tipos de conjunções coordenativas:

|                        |                                                                        |                                                                                                                 |
| ---------------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **  <br>Aditivas**     | expressam **adição**                                                   | **Ex.:** e, também, além disso, bem como, ademais, não só, mas também.                                          |
| **  <br>Adversativas** | possuem ideia de **contraste ou oposição**                             | **Ex**.: mas, porém, contudo, todavia, entretanto, no entanto.                                                  |
| **Alternativas**       | indicam **escolha ou alternância**                                     | **Ex**.: ou... ou, quer... quer, seja... seja, ora... ora.                                                      |
| **  <br>Conclusivas**  | Ligam orações ou palavras com sentido de **conclusão ou consequência** | **Ex**.: logo, portanto, então,<br><br>por isso, assim, por conseguinte, destarte, pois (quando vem deslocado). |
| **  <br>Explicativas** | Ligam orações ou palavras com sentido de **justificativa, explicação** | **Ex**.: que, porque, pois (se vier no<br><br>início da oração), porquanto                                      |
