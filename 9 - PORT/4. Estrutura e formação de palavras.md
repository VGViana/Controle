# **1. FORMAÇÃO DE PALAVRAS:**

O processo de formação de palavras refere-se aos **mecanismos** e **regras** que a Língua Portuguesa utiliza para criar novas palavras a partir de unidades menores, como: **<span style="color:#b8bb26">raízes, prefixos e sufixos.</span>**

Vamos aos conceitos:

## **1.1 RADICAL**: 

É a **raiz** da palavra. É a **<u>base indivisível</u>** da palavra, da qual diversas outras podem derivar.

**Ex.:** **Radical: "_pedr_ "**

**Palavras derivadas:** **pedr**eiro, **pedr**egulho, em**pedr**ado, a**pedr**ejar.

## **1.2 AFIXOS:** 

São os acréscimos feitos ao radical que mudam o sentido ou a classe gramatical da palavra.

**Divide-se em:**

|              |                           |                        |
| ------------ | ------------------------- | ---------------------- |
| **Prefixos** | vêm **antes** do radical  | **Ex.: in**feliz.      |
| **Sufixos**  | vêm **depois** do radical | **Ex**.: leal**dade**. |

## **1.3 DESINÊNCIAS:**

Possuem função exclusiva de flexionar nomes e verbos. Não formam novas palavras, mas sim **variações de uma mesma palavra**. 

**Podem ser de:**

|                                   |                         |
| --------------------------------- | ----------------------- |
| **Gênero (masculino / feminino)** | menin**o** / menin**a** |
| **Número (singular / plural)**    | moto / moto**s**        |
| **Tempo verbal**                  | falou / fala**va**      |
| **Pessoa**                        | era / era**m**          |

## **1.4 VOGAL TEMÁTICA E TEMA:**

A vogal temática é um **<span style="color:#b8bb26">elemento de ligação entre o radical e as desinências</span> (ou sufixos).

A vogal temática **não tem sentido próprio**, mas serve para finalizar o radical, unir o radical às desinências ou para indicar a conjugação do verbo.

**Ex.:** **MARES**

MAR + **E (vogal temática)**+ S (desinência de número)

## **1.5 PROCESSO DE FORMAÇÃO DE PALAVRAS:**

Os principais processos são a **composição** e a **derivação**. A palavra derivada é aquela que foi formada a partir de outra. 

**Obs.:** A palavra primitiva não deriva de nenhuma palavra anterior.

|                |                    |
| -------------- | ------------------ |
| **Composição** | Radical + Radical. |
| **Derivação**  | Radical + Afixo.   |

### **1.5.1 COMPOSIÇÃO:**

A composição é o processo de formação de palavras que consiste em **unir radicais**. 

**Pode ocorrer por:**

|                        |                                                                   |                                                                                                   |
| ---------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **  <br>Justaposição** | Os radicais **são conservados**, não perdem elementos estruturais | **Ex**.: **passatempo** (passa + tempo), **dezoito** (dez + oito), **paraquedas** (para + quedas) |
| **  <br>Aglutinação**  | Os radicais **sofrem alteração**, perdem letras.                  | **Ex**.: **planalto** (plano + alto), **lobisomem** (lobo + homem), **embora** (em + boa + hora). |

### **1.5.2 DERIVAÇÃO:**

A derivação é a formação de **palavras novas <span style="color:#b8bb26">a partir da união de radicais</span>** com prefixos ou sufixos **ou pela supressão de elementos de uma palavra primitiva**.

**A derivação pode ser:**

|                              |                                                                                                                                                                                                     |                                                                                                                                                          |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Prefixal**                 | é a **união** de Prefixo + Radical ou Palavra                                                                                                                                                       | **Ex**.: **anormal** (prefixo "a" + palavra "normal"), **injusto** (prefixo "in" + palavra "justo").                                                     |
| **Sufixal**                  | é a formação de nova palavra pelo acréscimo de sufixos.                                                                                                                                             | **Ex**.: **felicidade** (radical "felici" + sufixo "dade"), **emagrecimento** (radical "emagreci" + sufixo "mento").                                     |
| **Prefixal e Sufixal**       | é a **união** de Prefixo + Sufixo. Além disso, esses termos **são independentes**, ou seja, a retirada do prefixo ou do sufixo ainda resulta numa palavra que existe na Língua Portuguesa.          | **Ex**.: **des**leal**dade**, **ultra**passa**gem**, **re**considera**ção**.                                                                             |
| **Parassintética**           | é a união de Prefixo + Sufixo. Porém, esses termos **são dependentes,** ou seja, a retirada do prefixo ou do sufixo resulta numa palavra inexistente na Língua Portuguesa.                          | **Ex**.: **em**agr**ecer**, **a**cebol**ado**, **sub**terrâ**neo**.                                                                                      |
| **Imprópria (ou conversão)** | é a simples **mudança de classe gramatical** da palavra, que não sofre nenhuma alteração, mas muda de classe. Acontece muito com a chamada substantivação (transformação da palavra em substantivo) | **Ex**.: Olhar é verbo. "O olhar" é substantivo. A presença do artigo definido antes do verbo muda sua classe gramatical, passando a ser um substantivo. |
| **Regressiva**               | é a **formação de substantivos abstratos** que derivam de verbos. Há redução de radical.                                                                                                            | **Ex**.: pescar / pesca, atrasar / atraso, dançar / dança.                                                                                               |

## **1.6 OUTROS PROCESSOS IMPORTANTES DE FORMAÇÃO DE PALAVRAS:**

|                           |                                                                                                                                                                                         |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Abreviação ou redução** | **fotografia** = foto / **motocicleta** = moto / **televisão** = tv                                                                                                                     |
| **Siglas**                | Universidade Federal do Rio de Janeiro (UFRJ) / PIB (Produto Interno Bruto)                                                                                                             |
| **Hibridismo**            | formação de palavras a partir de radicais diferentes. **Ex**.: burocracia (_buro:_ francês / _cracia:_ grego)                                                                           |
| **Estrangeirismo**        | pizza, shopping, abajur                                                                                                                                                                 |
| **Onomatopeias**          | formação de palavras a partir da reprodução do som natural de algo. **Ex**.: tique-taque (relógio), zum-zum (abelha), au au (cachorro), blá blá blá (conversa).                         |
| **Neologismo**            | é a invenção de palavra nova para atender às necessidades novas dos falantes. **Ex**.: BFF (best friend forever), Portunhol (português + espanhol), Apertamento (aperto + apartamento). |
