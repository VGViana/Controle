# **1.SONS, LETRAS, FONEMAS, ACENTUAÇÃO, HÍFEN, ORTOGRAFIA**

## **1.1 SONS**

Ao estudo dos sons dá-se o nome de **FONÉTICA.**

A **Fonologia** é o estudo dos fonemas e de como eles funcionam no sistema linguístico. A Fonética, por sua vez, estuda os sons da fala de forma mais geral, incluindo aspectos físicos e fisiológicos.

## **1.2 FONEMAS**

Os **fonemas,** por sua vez, são os elementos sonoros mais simples que existem e fazem **distinção entre duas palavras**. Por exemplo, em português, os sons /p/ e /b/ são fonemas distintos porque diferenciam palavras como "pato" e "bato". Podem ser:

- **<span style="color:#d3869b">fonemas vocálicos</span>**: representam as **vogais.** _(A, E, I, O, U)._
- **<span style="color: #d79921">fonemas consonantais</span>**: representam as **consoantes.** _(B, C, D, F, G)._

**<span style="color:#fb4934"><u>Atenção</u></span>:** Não confunda letras com fonemas. <u>Letra é a representação gráfica de um som.</u> **Nem toda letra possui um som** (lembre-se da letra H).

**Exemplo:** 

- A palavra "casa" tem 4 letras, mas 4 fonemas (/k/, /a/, /z/, /a/).
- A palavra "hora" tem 4 letras, mas 3 fonemas (/o/, /r/, /a/), pois **H (H)** → **não tem som** (mudo)

**<span style="color:#83a598"><u>Sílaba</u></span>:** é a **junção de fonemas** numa única emissão de ar. Não existe sílaba sem vogal. As palavras podem ser classificadas como:

- **monossílabas:** **uma** única sílaba. _(Ex.: pé)_
- **dissílabas:** **duas** sílabas. _(Ex.: por-ta)_
- **trissílabas:** **três** sílabas. _(Ex.: es-pe-ra)_
- **polissílabas:** **quatro** sílabas. _(Ex.: cho-co-la-te)_

**<span style="color:#83a598"><u>Vogais</u></span>**: A vogal é o som **mais forte** da sílaba, pronunciado com a passagem livre de ar pela boca. Elas são a base da sílaba na Língua Portuguesa. **Existe apenas uma vogal em cada sílaba**.

| **Vogais: A, E, I, O, U** |
| ------------------------- |

**<span style="color:#83a598"><u>Semivogal</u></span>**: são mais **fracas,** quando comparadas à vogal. As semivogais são representadas pelas letras **I** e **U** quando aparecem ao lado de uma vogal na mesma sílaba, formando ditongos ou tritongos.

**Ex.:** letras _I_ e _U_, quando estiverem acompanhando outra vogal dentro de uma mesma sílaba, atuam como semivogais:

| T**ou**-ro**.** | **_(O:_** _vogal **/ U:** semivogal**)**_ |
| --------------- | ----------------------------------------- |
| Cá-r**ie**.     | _(**I**: semivogal / **E**: vogal)_       |

**<span style="color:#83a598"><u>Encontros vocálicos</u></span>**: são a união de **dois ou mais fonemas** vocálicos. São eles:

- **Ditongo**
- **Tritongo**
- **Hiato**

**<span style="color:#83a598"><u>Ditongo</u></span>**: junção de **<u>dois</u>** sons vocálicos numa única sílaba. (**D**itongo = **<span style="color: #d79921">DOIS</span>**)

| **Ex.: viu**, ca-**iu**, t**ou**-ro. |
| ------------------------------------ |

| - **Ditongo Crescente:** semivogal + vogal                                            | _(Ex.: histór**ia**, cár**ie**)_ |
| ------------------------------------------------------------------------------------- | -------------------------------- |
| - **Ditongo Decrescente:** vogal + semivogal                                          | _(Ex.: t**ou**ro, p**ei**xe)_    |
| - **Ditongo Oral:** quando o som sai completamente pela boca (sem ressonância nasal). | _(Ex.:boi)_                      |
| - **Ditongo Nasal:** quando o som sai pelo nariz                                      | _(Ex.: mãe, pão)_                |

**<span style="color:#83a598"><u>Tritongo</u></span>:** junção de **<u>três</u>** sons vocálicos numa única sílaba. (**Tri**tongo = **<span style="color: #d79921">TRÊS</span>**)

| **Ex.:** ig**uai**s, q**uão**. |
| ------------------------------ |

| - **Tritongo Oral: o som sai apenas pela boca.** | Ex.: ig**uai**s. |
| ------------------------------------------------ | ---------------- |
| - **Tritongo Nasal: o som sai pelo nariz.**      | Ex.: q**uão**.   |

**<span style="color:#83a598"><u>Hiato</u></span>:** é quando duas vogais estão em **<span style="color: #d79921">sílabas diferentes</span>.**

| **Ex.:** s**a-í**-da, pre-j**u-í**-zo. |
| -------------------------------------- |

**<span style="color:#83a598"><u>Dígrafo</u></span>:** ocorre quando **duas letras** representam um **<span style="color:#fb4934">único som</span>**.

Pode ser classificado em:

**1 –** Dígrafos **Consonantais**
**2 –** Dígrafos **Vocálicos**

| - **Dígrafos Consonantais** | **CH, LH, NH, RR, SS, SC, SÇ, XC, QU, GU** | **Ch**ave, fi**lh**o, ba**nh**o, ca**rr**o, pa**ss**ar, de**sc**er, de**sç**o, e**xc**elente, **qu**adro, **gu**erra. |
| --------------------------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------- |

**<span style="color:#fb4934">Atenção</span>. Dígrafos QU e GU:**

Eles são dígrafos consonantais somente quando o **<u>"U" não é pronunciado</u>**. Veja:

****QU** →**  quilo

Pronúncia: **/ˈki.lu/** 

**GU** → guerra

Pronúncia: /**gé**rra/

**Obs.:** O "U**" não é pronunciado**.

→ G + U formam um som só → dígrafo consonantal.

| - **Dígrafos Vocálicos** | **AM, AN, EM, EN, IM, IN, OM, ON, UM, UN** | C**am**po, **em**boscada, f**im**, c**om**prar, **um**bigo, **an**ta, **en**tão, **in**fiel, **on**da, **un**tar. |
| ------------------------ | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |

##  **1.3. ACENTUAÇÃO**

**<span style="color:#83a598"><u>Tonicidade</u></span>**: As sílabas podem ser **fortes (tônicas)** ou fracas (átonas). A sílaba tônica é a que recebe maior intensidade na pronúncia da palavra.

**<span style="color:#83a598"><u>Sílaba tônica</u></span>:** é a sílaba mais **forte** de uma palavra.

**<u>BIZU</u>:** Para identificá-la, imagine que você está na porta da casa de alguém e começa a chamar por essa pessoa até que ela atenda. Imagine que essa pessoa se chama Fernando. Ao chamá-lo, você vai "demorar" mais na sílaba "Fer-**<u>nan</u>**-do": é a sílaba tônica.

**<span style="color:#fb4934"><u>Obs.:</u></span>** Em cada palavra haverá **apenas uma sílaba forte**. Todas as outras serão fracas.

**<span style="color:#83a598"><u>Monossílabas</u></span>:**

Um monossílabo tônico é uma palavra de uma só sílaba.

Acentuam-se os monossílabos tônicos terminados em: **A(S), E(S), O(S).**

**Ex.:**

| **A - AS** | pá, já, lá, más       |
| ---------- | --------------------- |
| **E - ES** | pé, fé, dê, mês, três |
| **O - OS** | pó, só, nós           |

**Palavras com <u>duas ou mais</u> sílabas**: Podem ser:

| **Oxítonas**       | **Última sílaba mais forte**    | Ca**fé.**   |
| ------------------ | ------------------------------- | ----------- |
| **Paroxítonas**    | Penúltima sílaba mais forte     | Sa**pa**to. |
| **Proparoxítomas** | Antepenúltima sílaba mais forte | **Pá**gina. |

**<span style="color:#b8bb26"><u>Oxítonas</u></span>:**

São acentuadas as oxítonas terminadas em **A, E, O,** seguidas ou não de "s", e em ditongos abertos **ÉU, ÉI, ÓI**. _Ex.: sofá, você, avó, chapéu, papéis, heróis._ 

 Também são acentuadas as terminadas em **EM ou ENS.** _Ex: ninguém, também, armazéns, porém, parabéns._

 O _Novo Acordo Ortográfico_ **não afeta as palavras oxítonas** (onde a sílaba tônica está na última posição), que **continuam acentuadas**:

- **anéis, pastéis, heróis** (sem mudança)

Se oxítonas terminarem em **R, L, Z, N, X, I, U, UM, PS, US** não serão acentuadas, pois essas **seguem a regra das** **<u>paroxítonas</u>**❗

- **Exemplos:** **amor, anel, raiz, hífen, tórax, urubu, álbum, vírus**

**<span style="color:#b8bb26"><u>Paroxítonas</u></span>:**

Todas as paroxítonas são acentuadas, **exceto** as terminadas em A, E, O, EM, ENS.

Acentuam-se as terminadas em **L, N, R, X, I, IS, US, UM, UNS, Ã, ÃO, ÃOS, ÃS, ÃES.**

**Ex.:** fácil, revólver, lápis, vírus, bíceps.

_**<span style="color:#fb4934">Obs.:</span>** Assim, a palavra "problema" não é acentuada._

- **Ditongos nas Paroxítonas:** 

- Palavras **paroxítonas** (penúltima sílaba tônica) terminadas em **ditongo** são **sempre acentuadas**, salvo exceções.

**🔹 Exemplos de palavras acentuadas:**

- Com ditongos orais: **série, tênue, história, júri**
- Com ditongos nasais: **bênção, ímã**

**❌ Mudanças do Acordo Ortográfico:**

- **Fim do trema**: **linguiça, tranquilo** (antes: lingüiça, tranqüilo).
- **Fim do acento em hiatos com “i” e “u” após ditongo** (se a segunda vogal não for tônica):

- Ex.: **feiura, baiuca** (antes: feiúra, baiúca).

**<span style="color:#b8bb26"><u>Proparoxítonas</u></span>:**

**Todas** as palavras proparoxítonas devem ser acentuadas.

**Ex.:**

- Público, lâmpada, música, médico, lógico.

💡 **Dica:** Se a sílaba forte for a **terceira** contando do fim da palavra, pode apostar que ela leva acento!

As **proparoxítonas eventuais** são palavras que, na prática, poderiam ser classificadas como proparoxítonas, mas seguem a **regra das paroxítonas** porque a última sílaba é uma vogal fraca e a penúltima sílaba recebe o acento natural. Elas mantêm a **acentuação das paroxítonas** porque terminam em **vogal, ditongo ou consoante que permite o som prolongado**.

**Ex.:**

- Hélice, tórax, fênix

### **1.3.1 ACENTUAÇÃO DO HIATO:**

O **hiato** é o **encontro de duas vogais, mas em sílabas diferentes**. A razão do acento, em alguns hiatos, é impedir que se leia como um ditongo (encontro de uma vogal com uma semivogal, ambos na mesma sílaba). Veja:

|             |           |                                   |
| ----------- | --------- | --------------------------------- |
| **Ditongo** | Ex.: Cai  | Vogal + semivogal mesma sílaba    |
| **Hiato**   | Ex.: Ca-í | Duas vogais em sílabas diferentes |

**<span style="color:#b8bb26"><u>Regra</u></span>:** Devemos **acentuar** o **I e o U tônicos**, em hiato, quando:

|                                  |                                  |
| -------------------------------- | -------------------------------- |
| **1 – Estão sozinhos na sílaba** | Ex.: “sa-í-da”, “a-ça-í          |
| **2 – São seguidos de “S”.**     | Ex.: “fa-ís-ca”, “ba-la-ús-tre”. |

**Exemplos de palavras com hiato acentuado**:

- Pa-ís
- Ba-ú
- Fa-ís-ca
- sa-í-da 

**<span style="color:#fb4934">Atenção</span>.** Em sentido contrário, o I e o U tônicos **<u>NÃO</u>**<u> são acentuadas</u> quando formam sílaba com letra que **não seja S**. Veja:

**Ex.:**

- juiz
- ruim
- saiu
- cair
- amendoim
- contribuiu

**<u>Exceções</u>:**

1. **Hiato antes de NH**: Não se acentua o **I** ou **U** tônico quando o hiato é seguido de **NH** na próxima sílaba.

**Ex.:**

- rainha
- bainha
- moinho

2. **I ou U tônico após ditongo decrescente em paroxítonas**: Não se acentua o **I** ou **U** tônico quando ele vem após um ditongo decrescente em palavras paroxítonas.

**Ex**.:

- **feiura** (não mais _feiúra_)
- **bocaiuva** (não mais _bocaúva_)

**<span style="color: #d79921">Bizu</span>:** Se **"i" ou "u" formam hiato**, estão **sozinhos na sílaba**, **são tônicos** e **não vêm depois de ditongo em paroxítonas**, → **<u>levam acento</u>.**

### **1.3.2. ACENTOS DIFERENCIAIS:**

Os **acentos diferenciais** são usados para distinguir palavras que têm a mesma grafia, mas significados ou funções diferentes. Após o **Acordo Ortográfico de 2009**, apenas alguns acentos diferenciais foram mantidos:

**<span style="color:#83a598">Acentos Diferenciais <u>Mantidos</u></span>**

|                       |                                                           |
| --------------------- | --------------------------------------------------------- |
| **por** (preposição)  | **pôr** (verbo)                                           |
| **tem** (singular)    | **têm** (plural)                                          |
| **vem** (singular)    | **vêm** (plural) – do verbo **VIR**, não do verbo **VER** |
| **pode** (presente)   | **pôde** (pretérito)                                      |
| **mantém** (singular) | **mantêm** (plural)                                       |

**<span style="color:#83a598">Acentos Diferenciais <u>Facultativos</u></span>**

|                      |                         |
| -------------------- | ----------------------- |
| **forma** (verbo)    | **fôrma** (substantivo) |
| **demos** (presente) | **dêmos** (subjuntivo)  |

**<span style="color:#83a598">Acentos Diferenciais <u>Abolidos</u></span> <span style="color:#fb4934">(NÃO USA!!!)</span>**

- **pela** (preposição + artigo) / **pela** (verbo pelar).
- **polo** (esporte) / **polo** (antiga forma de "por o").
- **pelo** (substantivo) / **pelo** (verbo pelar).
- **pera** (fruta) / **pera** (preposição arcaica).

## **1.4 EMPREGO DO HÍFEN:**

**<span style="color:#83a598">Emprega-se o HÍFEN</span>:**

**<span style="color: #d79921">1ª regra:</span>** Usa-se o hífen quando o prefixo termina com uma vogal e o segundo elemento começa com a **mesma vogal**.

**Ex.:**

|                       |                                                                  |
| --------------------- | ---------------------------------------------------------------- |
| **micro-ondas**       | **(prefixo _micro_ termina com "o" + _ondas_ começa com "o")**   |
| **anti-inflamatório** | (prefixo _anti_ termina com "i" + _inflamatório_ começa com "i") |
| **contra-ataque**     | (prefixo _contra_ termina com "a" + _ataque_ começa com "a")     |

**<span style="color: #d79921">2ª regra:</span>** **Prefixo** termina com -R + **palavra começa** com R → usa-se o hífen.

**Ex.:**

|                  |
| ---------------- |
| Inter - regional |

**<span style="color: #d79921">3ª regra:</span>** **Prefixo** termina com -R + **palavra começa** com H → também usa o hífen.

**Ex.:**

|                 |
| --------------- |
| **Super-homem** |

**<span style="color: #d79921">4ª regra:</span>** **Prefixo** termina por vogal e o **próximo elemento inicia** por “r” ou “s”: juntam-se os termos e dobra-se o “r” ou “s”.

**Ex.:**

|                                |
| ------------------------------ |
| **Contrassenso, contrarrazão** |

**<span style="color:#83a598">Hífen nas palavras compostas</span>:**

**<span style="color: #d79921">1ª regra:</span>** Na composição com **verbos, substantivos, adjetivos, numerais**

**Ex.:**

|                                     |
| ----------------------------------- |
| **amor-perfeito** (subst. + subst.) |
| **azul-claro** (adj. + adj.)        |

**<span style="color: #d79921">2ª regra:</span>** Com o elemento **mal**, e o próximo termo inicia por **vogal, h ou l.**

**Ex.:**

|                    |
| ------------------ |
| **mal-afortunado** |
| **mal-humorado**   |
| **mal-limpo**      |

### **1.4.1** **EMPREGO DO HÍFEN:**

**<span style="color:#b8bb26"><u>Hifens com prefixos</u></span>:** _ante-, anti-, contra-, extra-, hiper-, inter-, intra-, sob-, sobre-, sub-, super-, auto-, micro-, mini-, pan-, pluri-, pre-, pro-, pseudo-, retro-, semi-, tele-..._

Emprega-se o hífen nos seguintes casos:

- **<span style="color:#fb4934"><u>Antes de H</u></span>:** anti-higiênico, extra-humano, super-homem, sub-hepático.
- **<span style="color:#fb4934"><u>Quando o prefixo termina com a mesma letra com que o segundo elemento se inicia</u></span>:** auto-observação, micro-ondas, semi-interno, contra-almirante.
- **<span style="color:#fb4934"><u>Nas formações com os prefixos _além-, aquém-, bem-, ex-, pós, pré-, pró-, recém-, sem-, vice-_:</u></span>** ex-presidente, pré-natal, recém-nascido, sem-vergonha.
- **<span style="color:#fb4934"><u>Nas formações com o prefixo _mal-,_ emprega-se o hífen quando o segundo elemento começa com vogal, H ou L:</u></span>** mal-afortunado, mal-entendido, mal-humorado, mal-limpo. **Não** se usa o hífen, como "malnascido" ou "malvestido" (pois o segundo elemento começa com consoante que não seja "H" ou "L").
- **<span style="color:#fb4934"><u>Nas formações com os prefixos _ab-, ob-, sob-, sub-, ad-_ cujo elemento seguinte começa com R:</u></span>** ab-rupto, ob-rogar, sob-roda, sub-reitor, ad-renal.

**<span style="color:#b8bb26"><u>Hifens em locuções:</u></span>**

Nas locuções de qualquer tipo (adverbiais, prepositivas, conjuncionais...), **<span style="color:#fb4934"><u>não se emprega o hífen,</u></span> <span style="color:#83a598"><u>em regra geral</u></span>**. Veja os seguintes exemplos:

- fim de semana
- sala de jantar
- cor de vinho
- a fim de
- por baixo de
- acerca de
- ao passo que
- logo que
- visto que

**<span style="color:#fb4934"><u>Obs</u></span>**.: Algumas **<span style="color:#fb4934"><u>exceções</u></span>** já consagradas pelo uso são: **<span style="color:#fb4934">água-de-colônia, cor-de-rosa, mais-que-perfeito, pé-de-meia.</span>**

**<span style="color:#fb4934">Obs</span>.:** Em algumas palavras compostas por justaposição, o hífen ainda é usado, como: **"<span style="color:#fb4934">segunda-feira" e "guarda-chuva</span>".**

## **1.5 EMPREGO DAS LETRAS:**

**<span style="color:#b8bb26">O uso do</span> <span style="color:#b8bb26">S</span>**:

- depois de ditongos: _**<span style="color:#b8bb26">coisa, lousa</span>**._
- em nomes próprios com som de Z: _**<span style="color:#b8bb26">Brasil, Sousa</span>**._
- no sufixo -oso: _**<span style="color:#b8bb26">cheiroso, dengoso</span>**._
- nos derivados do verbo querer: _**<span style="color:#b8bb26">quis, quisesse</span>**._
- nos derivados do verbo pôr: _**<span style="color:#b8bb26">pus, pusesse</span>**._
- no sufixo -ense, formador de adjetivo: _**<span style="color:#b8bb26">canadense, catarinense</span>**._
- no sufixo -isa, indicando profissão ou ocupação feminina: _**<span style="color:#b8bb26">poetisa, profetisa</span>**._
- nos sufixos -ês, - esa, indicando origem, nacionalidade ou posição social: _**<span style="color:#b8bb26">japonês, camponesa</span>**._
- nas palavras derivadas de outras que possuam S no radical: _**<span style="color:#b8bb26">casa/casinha, análise/analisado</span>**._
- nos derivados de verbos que tragam o encontro consonantal -nd: _**<span style="color:#b8bb26">pretende/pretensão, suspende/suspensão</span>**._
- alguns verbos terminados em "sar" mantêm o "S" quando conjugados, _como "analisar" → "analiso", "atrasar" → "atraso"._

**<span style="color:#fe8019">O uso do Z</span>**:

- nas palavras derivadas de primitiva com Z: _**<span style="color:#fe8019">cruz/cruzamento, deslize/deslizar</span>**._
- no sufixo -ez, -eza, formadores de substantivos abstratos a partir de adjetivos: _**<span style="color:#fe8019">macio/maciez, belo/beleza</span>**._
- no sufixo -izar, formador de verbos: _**<span style="color:#fe8019">hospital/hospitalizar, útil/utilizar</span>**._
- nos verbos terminados em -uzir e seus derivados: _**<span style="color:#fe8019">conduzir/conduzo, deduzir/deduziu,  produzir/produziram</span>**._
- no sufixo -zinho, formador de diminutivo: _**<span style="color:#fe8019">mãezinha, paizinho, cãozinho, pobrezinho</span>**._

**<span style="color:#d3869b">O uso do H</span>**:

- o H inicial deve ser usado quando a etimologia o justifique: _**<span style="color:#d3869b">hiato, harpa, hélice, hóspede, hábil</span>**._
- o H deve ser eliminado do interior das palavras, se elas formarem um composto ou derivado sem hífen: _**<span style="color:#d3869b">desidratar, desonra, inumano, desabitado</span>**._
- o H deve ser usado no final de interjeições: _**<span style="color:#d3869b">ah!, oh!, ih!</span>**._

**<span style="color:#83a598">O uso do X</span>**:

- em geral, após ditongo: _**<span style="color:#83a598">peixe, caixa, trouxa</span>**._
- normalmente, após a sílaba inicial en-: _**<span style="color:#83a598">enxoval, enxada, enxaqueca</span>**._
- depois da sílaba inicial me-: _**<span style="color:#83a598">mexer, mexilhão, mexerica</span>**._

**<span style="color: #d79921">O uso do SS</span>**:

Ocorre nas seguintes situações:

- ced - cess: _**<span style="color: #d79921">ceder/cessão, conceder/concessão</span>**._
- gred - gress: _**<span style="color: #d79921">agredir/agressão, regredir/regressão</span>**._
- prim-press: _**<span style="color: #d79921">imprimir/impressão, oprimir/opressão</span>**._
- tir-ssão: _**<span style="color: #d79921">discutir/discussão, permitir/permissão</span>**._

**O uso do Ç**:

- nas palavras de origem árabe, tupi ou africana: **_açúcar, caçula, miçanga_**.
- após ditongo: _**louça, traição**_.
- na relação ter-tenção: _**obter/obtenção, reter/retenção**_.
- no sufixo "-aça", "-aço", indicativos de aumentativo (ex.: "barbaça", "ricaço").

## **1.6 LETRAS MAIÚSCULAS:**

**<u>Usamos letras Maiúsculas:</u>**

|                                                                                                                                                                                                                                                                                                                              |                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **Nomes Próprios**                                                                                                                                                                                                                                                                                                           | Ex.: Larissa, Bruno, Austrália, Senado Federal       |
| **Nomes Comuns**                                                                                                                                                                                                                                                                                                             | Ex.: o País, a Nação, o Estado                       |
| **Logradouros Públicos**                                                                                                                                                                                                                                                                                                     | Ex.: Avenida Brasil, Rodovia Amaral Peixoto          |
| **Pronomes de Tratamento (e abreviações)**                                                                                                                                                                                                                                                                                   | Ex.: Vossa Excelência, V. Exa                        |
| **Início de período / citação**                                                                                                                                                                                                                                                                                              | Ex.: "Tudo vale a pena quando a alma não é pequena." |
| **Datas oficiais, de festas religiosas ou de atos solenes**                                                                                                                                                                                                                                                                  | Ex.: Sexta-feira Santa, Dia das Mães                 |
| **Títulos de livros, de teses, de jornais, de filmes, de músicas:**                                                                                                                                                                                                                                                          | Ex.: O sorriso de Monalisa, Dom Casmurro.            |
| **Pontos cardeais ou colaterais  <br>  <br><font color="#fb4934">Obs</font>.: Os pontos cardeais só levam maiúscula se indicarem regiões geográficas específicas, como:  <br>  <br>- “O Sul do Brasil é muito frio”. ✅  <br>- "Viajamos para o norte do país." ("norte" aqui** **é direção, então deve ser minúsculo). ❌  ** | Ex.: Norte, Sul, Noroeste                            |

## **1.7 SIGLAS E ABREVIAÇÕES:**

**<u>Sigla</ug>:** é a redução de palavras às suas letras ou sílabas iniciais.

- Siglas de até três letras são grafadas com letra maiúscula: **_RJ, MG, DF_**.
- Siglas com mais de três letras são grafadas com letra maiúscula quando cada letra é pronunciada separadamente: **_UFRJ, BNDES, CCBB_**. Quando são lidas como uma palavra, apenas a inicial é maiúscula **(Unesco, Unicef).**
- O plural de siglas ocorre com o acréscimo de um s, minúsculo: **_PDFs, UPAs_**.
	- **<span style="color:#fb4934">Observação</span>:** O uso do **apóstrofo antes do "s" é aceito em casos onde a sigla é difícil de pluralizar** (ex.: CD's, UPA's), embora seja <u>opcional</u>.

**<u>Abreviação</u>**: é a redução de uma palavra, alterando tanto a grafia quanto a pronúncia, mas mantendo seu significado compreensível.

- motocicleta / **moto**
- fotografia / **foto**
- quilograma / **quilo**

**<u>OBS</u>**.: Há diferença entre **ABREVIAÇÃO** e **ABREVIATURA**. Na abreviatura, a redução ocorre apenas na grafia, nunca na pronúncia.

**Ex.:** advocacia / adv., apartamento / apart., academia / acad.

## **1.8 EXPRESSÕES PROBLEMÁTICAS:**

**<span style="color:#83a598"><u>O USO DOS PORQUÊS</u></span>**:

**<span style="color:#83a598"><u>POR QUE</u></span>:**

Quando usar **por que**?

O “**por que**”, separado e sem acento, **introduz uma pergunta** ou estabelece uma **relação** com o termo anterior da frase.

É utilizado:

|                                                                                                                                                                              |                                                                                                                                    |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **No início de frase interrogativa direta (a pergunta é explícita).**                                                                                                        | **Ex.: Por que você estuda tanto?**                                                                                                |
| **No meio de frase interrogativa indireta (na construção da frase, a pergunta está implícita), quando depois dele estiverem subentendidas as palavras “razão” ou “motivo”.** | **_Ex.: Não sei por que você continua insistindo nessas ideias. = Não sei por que razão você continua insistindo nessas ideias._** |
| **No papel de preposição (por) seguida por pronome relativo (que), pode ser substituído por “pela qual”, “pelo qual”, “pelas quais”, “pelos quais”.**                        | **_Ex.: As estradas por que passamos eram longas._**                                                                               |

**<span style="color:#83a598"><u>PORQUE</u></span>:**

Quando usar **porque**?

O **porque**, junto e sem acento, é usado, principalmente, em **respostas e em explicações**. Exerce a função de conjunção subordinativa **causal** ou conjunção coordenada **explicativa.** 

É uma conjunção que une duas orações. Indica o motivo, a razão de algo ou a explicação de alguma coisa.

Pode ser perfeitamente substituído por "**já que**", "**visto que**", "**uma vez que**", "**pois**".

**O porque, junto e sem acento, pode iniciar uma frase ou aparecer no meio dela.**

Embora o "porque" normalmente não inicie frases afirmativas, pode ser usado dessa forma em contextos específicos, como na explicação do realce:

|                                                    |
| -------------------------------------------------- |
| **Ex.: Porque acredite, o investimento foi alto.** |

Aqui, a pausa natural sugere que poderia haver uma pontuação diferente, como:

|                                                     |
| --------------------------------------------------- |
| **Ex.: Porque, acredite, o investimento foi alto.** |

**<span style="color:#fb4934"><u>Importante</u></span>: O “porque” também pode ser usado como para enfatizar uma ideia, atuando como um termo de realce**. Veja:

|                                                                                      |
| ------------------------------------------------------------------------------------ |
| **Ex.: Espero que o projeto seja aceito. Porque acredite, o investimento foi alto.** |

**<span style="color:#fb4934">Atenção</span>!** Com ideia de realce, o “**porque”** pode ser suprimido da frase sem que seu sentido seja prejudicado.

|                                                                               |
| ----------------------------------------------------------------------------- |
| **Ex.: Espero que o projeto seja aceito. Acredite, o investimento foi alto.** |

**<span style="color:#fb4934"><u>Atenção</u></span>:** quando o “porque” estiver no início de frase, **não pode** ser substituído pela conjunção “pois”, por ter caráter explicativo (e não causal).

**<span style="color:#83a598"><u>POR QUÊ</u></span>:**

Quando usar **por quê**?

O **por quê**, separado e com acento circunflexo, é usado sempre no final da frase, seguido de pontuação. Pode vir logo antes do ponto final ou do ponto de interrogação.

|                                                                |
| -------------------------------------------------------------- |
| **Ex.: Você queria fazer aquela entrevista, por quê?**         |
| **Ex.: Você ficou em silêncio na reunião e nem sabe por quê.** |

**<span style="color:#fb4934"><u>Atenção</u></span>**: A única diferença desse “por quê” para o “por que” é a posição que ocupa na frase. Esquematizando:

|             |                                           |
| ----------- | ----------------------------------------- |
| **Por que** | **Aparece no início ou no meio da frase** |
| **Por quê** | Aparece no fim da frase                   |

**<span style="color:#83a598"><u>PORQUÊ</u></span>:**

Quando usar **porquê**?

O “**porquê**”, junto e com acento circunflexo, é **sempre** um **substantivo**. Possui o mesmo significado de **“razão”,** **“motivo”.**

Pode aparecer em <u>qualquer posição</u> dentro de uma frase.

Em frases, <u>sempre vem precedido por um artigo, um numeral ou um pronome.</u> 

|                                                |
| ---------------------------------------------- |
| **Ex.: Não sei o porquê de tanto medo.**       |
| **Ex.: Diga-me um porquê para tanto medo.**    |
| **Ex.: Não há nenhum porquê para tanto medo.** |

**<span style="color:#fb4934">Importante</span>:** por ser um substantivo, **pode ir para o plural**.

|                                                                                      |
| ------------------------------------------------------------------------------------ |
| **Ex.: Os executivos deram três porquês para executarmos o projeto neste semestre.** |

| **RESUMO** | **EXEMPLOS**                                                          |
| ---------- | --------------------------------------------------------------------- |
| POR QUE    | Por que você estuda tanto? <br><br>Não sei por que você estuda tanto. |
| POR QUÊ    | Você estuda tanto, por quê?                                           |
| PORQUE     | Estudo porque quero ser aprovado.                                     |
| PORQUÊ     | Diga-me um porquê para tanto estudo.                                  |

 **<span style="color:#83a598"><u>MAL / MAU:</u></span>**

|                                             |                                           |
| ------------------------------------------- | ----------------------------------------- |
| **Mal:** oposto de **“Bem”. É um adverbio** | **Ex.:** Estava se sentindo **mal** hoje. |
| **Mau:** oposto de **“Bom”. É um adjetivo** | **Ex.:** Ele é um **mau** amigo.          |

 **<span style="color:#83a598"><u>HÁ / A:</u></span>**

|                                                                                   |                                                                              |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **HÁ:** verbo impessoal “haver” (sentido de existir, indicação de tempo passado). | **Ex.: Há** dias em que me sinto esperançoso.                                |
| **A:** preposição, indicando limite, distância, direção ou tempo futuro.          | **Ex.:** Daqui **a** pouco vamos conversar / Estou **a** 100 metros de você. |

**<span style="color:#83a598"><u>ONDE / AONDE:</u></span>**

As duas formas estão **corretas** e indicam lugar, porém são utilizadas em situações diferentes.

**<span style="color:#83a598"><u>ONDE</u></span>:**

 Acompanha verbos com ideia de **permanência,** de ausência de movimento. Exemplos desse verbos: **_ficar, estar, morar._**

|                                                 |
| ----------------------------------------------- |
| **Onde** fica a sua clínica?                    |
| O hotel **onde** estamos hospedados é incrível. |
| **Onde** ela mora?                              |

**<span style="color:#83a598"><u>AONDE:</u></span>**

Acompanha verbos com ideia de **movimento** e regidos pela preposição **“a”**.

Exemplos desses verbos: **_ir, chegar, levar._**

|                                                                             |
| --------------------------------------------------------------------------- |
| **Aonde** você vai? (Vai A algum lugar)                                     |
| Não sei **aonde** você quer chegar com essa conversa. (Chega A algum lugar) |
| O motorista levará o rapaz **aonde** ele quiser. (Leva A algum lugar)       |

**<span style="color:#83a598"><u>MAS / MAIS</u></span>**:

|                                                        |                                                |
| ------------------------------------------------------ | ---------------------------------------------- |
| **MAS:** conjunção adversativa, como: porém, contudo.. | **Ex.:** Estou feliz, **mas** preocupado.      |
| **MAIS: oposto de menos / quantidade**                 | Ex.: Quanto **mais** estudo, **mais** aprendo. |

**<span style="color:#83a598"><u>A FIM / AFIM</u></span>**:

|                                                                              |                                                                                                       |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| **A FIM.:** locução com ideia de finalidade, propósito, objetivo, interesse. | **Ex.:** Estou **a fim** de aprender mais / Ela está **a fim** de você.                               |
| **AFIM.:** indica algo semelhante, próximo, correlato                        | **Ex.:** Somos parentes **afins** (próximos) / Raciocínio Lógico e Matemática são matérias **afins**. |

**<span style="color:#83a598"><u>A PAR / AO PAR:</u></span>**

|                                                                                                |                                                           |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **A PAR:** estar ciente de alguma coisa. É expressão invariável.                               | **Ex.:** Estou **a par** do ocorrido.                     |
| **AO PAR.:** só é usada em relação ao câmbio, para expressar equivalência econômica de moedas. | **Ex.:** Queria que o dólar estivesse **ao par** do real. |

**<span style="color:#83a598"><u>ACERCA / A CERCA / HÁ CERCA:</u></span>**

|                                                |                                                      |
| ---------------------------------------------- | ---------------------------------------------------- |
| **ACERCA: significa "a respeito de".**         | **Ex.:** Vamos conversar **acerca de** futebol.      |
| **A CERCA: quer dizer "por volta de".**        | **Ex.:** Estamos **a cerca de** 100 metros da praia. |
| **HÁ CERCA: significa "faz aproximadamente”.** | **Ex.:** **Há cerca de** dois anos que não a vejo.   |

**<span style="color:#83a598"><u>TÃO POUCO / TAMPOUCO:</u></span>**

|                                                       |                                                           |
| ----------------------------------------------------- | --------------------------------------------------------- |
| **TÃO POUCO: significa "muito pouco".**               | **_Ex.: Há tão pouco arroz para comermos._**              |
| **TAMPOUCO: quer dizer "muito menos", "também não".** | **_Ex.: Não quero sair de casa, tampouco ir ao cinema!_** |

**<span style="color:#83a598"><u>TRÁS / TRAZ:</u></span>**

|                                                                                                                                                                              |                                                             |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **TRÁS: advérbio: sinônimo de atrás, após, detrás. Sempre estará acompanhado de preposição.**                                                                                | **_Ex.: Por trás de tanto sucesso, existe muito esforço._** |
| **TRAZ: verbo "trazer", conjugado na terceira pessoa do singular do indicativo e na primeira pessoa do singular do imperativo. Quer dizer transportar, oferecer, conduzir.** | **_Ex.: Alguns dizem que dinheiro não traz felicidade._**   |

**<span style="color:#83a598"><u>CESSÃO / SESSÃO / SEÇÃO:</u></span>**

|                                              |                                                                    |
| -------------------------------------------- | ------------------------------------------------------------------ |
| **CESSÃO: ato de ceder.**                    | **_Ex.: Ela fez um contrato de cessão de direitos com o marido._** |
| **SESSÃO: período de tempo.**                | **_Ex.: A sessão de cinema durou duas horas e meia._**             |
| **SEÇÃO: ponto/local onde algo é dividido.** | **_Ex.: Essa seção é exclusiva para assinantes._**                 |

 **<span style="color:#83a598"><u>EM VEZ DE / AO INVÉS DE:</u></span>**

|                                                                                          |                                                   |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------- |
| **EM VEZ DE: significa "no lugar de".**                                                  | **_Ex.: Em vez de ir ao teatro, foi ao cinema._** |
| **AO INVÉS DE: a quer dizer "ao inverso de", "ao contrário de". Indica ideias opostas.** | **_Ex.: Ao invés de falar, calou._**              |

**DE MAIS / DEMAIS:**

|                                                                                     |                                            |
| ----------------------------------------------------------------------------------- | ------------------------------------------ |
| **DE MAIS: é uma locução adverbial, é o oposto a "de menos" e significa "a mais".** | **_Ex.: Tem arroz de mais nessa panela!_** |
| **DEMAIS: advérbio de intensidade. Significa "muito", "em exagero".**               | **_Ex.: Essa comida é boa demais!_**       |

**<span style="color:#83a598"><u>AO ENCONTRO DE / DE ENCONTRO A:</u></span>**

|                                                                                                   |                                                                   |
| ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| **AO ENCONTRO DE: significa "a favor de", "no sentido de". A ideia é de concordância.**           | **_Ex.: A menina correu ao encontro do namorado._**               |
| **DE ENCONTRO A: quer dizer "em sentido contrário", "em oposição a". A ideia é de discordância.** | **_Ex.: O carro, em alta velocidade, foi de encontro ao poste._** |

**<span style="color:#83a598"><u>SE NÃO / SENÃO:</u></span>**

|                                                                           |                                                             |
| ------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **SE NÃO:** significa **"caso não".** O "se" é uma conjunção condicional. | **_Ex.: Se não quiser ir à reunião, não haverá problema._** |

|                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **SENÃO**: possui alguns significados, como:<br><br>- do contrário. **_Ex.: Coma logo, senão vai esfriar._**<br>- mas sim. **_Ex.: Essa cor não é roxa nem preta, senão cinza._**<br>- a não ser, exceto. **_Ex.: Ninguém falou comigo, senão Maria._**<br>- mas também. **_Ex.: O sucesso depende não somente de esforço, senão de um pouco de sorte também._**<br>- obstáculo, falha, defeito. **_Ex.: Não encontrei um senão no seu discurso._** |
