As principais classes de palavras **VARIÁVEIS** são:

| **Substantivo**                                                                          | **Adjetivo**                                                                                                                        | **Artigo**                                                                                 | **Numeral**                                                                                | **Pronome**                                                                                                            | **Verbo**                                                                                                                                                                                                     |

## **1.1 SUBSTANTIVO**

É uma classe de palavras que tem a função de nomear seres, objetos, lugares, sentimentos, ideias, entre outros. Eles são essenciais para a construção da comunicação, pois dão nome às coisas que queremos expressar.

Existem diferentes tipos de substantivos, incluindo:

|                |                                                                                                                                   |                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Concretos**  | são aqueles que designam seres ou objetos que **têm existência física e podem ser percebidos pelos sentidos.**                    | _**Ex.:** cachorro, casa, árvore._                                                                     |
| **Abstratos**  | referem-se a **conceitos, sentimentos, estados ou qualidades**, sendo coisas que não podem ser percebidas pelos sentidos físicos. | _**Ex.:** amor, carinho, justiça_                                                                      |
| **Próprios**   | são aqueles que se referem a n**omes próprios de pessoas, lugares, instituições.**                                                | _**Ex.:** Natália, Universidade Federal do Rio de Janeiro, Itália._                                    |
| **Comuns**     | nomeiam s**eres de uma mesma espécie** de forma genérica.                                                                         | _**Ex.:** carro, livro, escola._                                                                       |
| **Coletivos**  | referem-se a um **conjunto de seres ou objetos da mesma espécie.**                                                                | _**Ex.:** cardume (conjunto de peixes) e rebanho (conjunto de animais)._                               |
| **Simples**    | são formados por apenas **uma palavra.**                                                                                          | _**Ex.**: flor, criança, chuva._                                                                       |
| **Compostos**  | são formados pela **junção de duas ou mais palavras.**                                                                            | _**Ex.:** guarda-chuva, couve-flor, pé-de-moleque._                                                    |
| **Primitivos** | são aqueles que **não se originam de outras palavras** da língua portuguesa.                                                      | _**Ex.**: sol, mar, pedra._                                                                            |
| **Derivados**  | são formados **a partir de outras palavras da Língua Portuguesa**, adicionando prefixos, sufixos ou outros elementos.             | _**Ex.:** floresta (derivado de "flor"), casinha (derivado de "casa") e marítimo (derivado de "mar")._ |

Quanto ao **gênero** (masculino/feminino), os substantivos podem ser:

| **Biformes**                                                                                                                   | **Uniformes**                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| apresentam **formas distintas** para indicar o gênero gramatical, ou seja, uma forma para o masculino e outra para o feminino. | possuem uma **única forma** que pode ser utilizada tanto para indicar o gênero masculino quanto o feminino.                                                                                                                                                                                                 |
| _**Ex.:** homem, mulher / cão, cadela / poeta, poetisa_                                                                        | **Eles podem ser:**<br><br>- Epicenos: Referem-se a **animais**. **Ex.:** a cobra, a águia.<br><br>- Sobrecomuns: Referem-se a **pessoas**. **Ex.:** a criança, a vítima.<br><br>- Comuns de dois gêneros: **forma única** para masculino e feminino. A distinção é pelo artigo. **Ex.:** o chefe, a chefe. |

### **1.1.1 Plural de substantivos compostos**:

Em regra, quando o termo é formado por classes **variáveis**, como substantivos, adjetivos, numerais e pronomes (exceto o verbo), **ambos variam**.

| **Substantivo + substantivo**         | **Numeral + substantivo**                  | **Adjetivo + substantivo**               |
| ------------------------------------- | ------------------------------------------ | ---------------------------------------- |
| _**Ex.:** couve-flor / couves-flores_ | _**Ex.:** segunda-feira / segundas-feiras_ | _**Ex.:** baixo-relevo / baixos-relevos_ |


Seguindo a mesma lógica, as classes **invariáveis** (e os verbos) não variam em número:

| **Verbo + substantivo**              | **Advérbio + adjetivo**                 | **Interjeição + substantivo**     |
| ------------------------------------ | --------------------------------------- | --------------------------------- |
| _**Ex.:** beija-flor / beija-flores_ | _**Ex.:** alto-falante / alto-falantes_ | _**Ex.:** ave-maria / ave-marias_ |


Porém, a regra comporta **<span style="color:#83a598"><u>exceções</u></span>:**

Na composição de **dois substantivos**, se o **segundo especificar o primeiro** por uma relação de tipo, semelhança ou finalidade, é mais comum que o segundo termo (por ser delimitador) fique no singular. Contudo, é também correto flexionar os dois!

**Ex.:**

|                          |                       |
| ------------------------ | --------------------- |
| **salários-família**     | **salários-famílias** |
| **licenças-maternidade** | licenças-maternidades |

Se a estrutura for **substantivo + preposição + substantivo**, apenas o primeiro item da composição se flexiona:

**Ex.:**

|                   |                  |
| ----------------- | ---------------- |
| **mão de obra**   | **mãos de obra** |
| **pé de moleque** | pés de moleque   |

**<span style="color:#fb4934"><u>Obs</u></span>**.: Lembrando que palavras **compostas ligadas por preposição perderam o hífen**: _Exs.: mão de obra, lua de mel, dia a dia, boca de urna, pé de moleque, pão de ló._

**<span style="color:#fb4934"><u>Obs</u></span>:** Essa regra é válida para a maioria dos casos, mas há exceções, como "pés de galinha" (que pode ser flexionado tanto no primeiro quanto no segundo termo). 

### **1.1.2 Grau do substantivo:**

O substantivo também pode variar em grau: **aumentativo** e **diminutivo.** É importante lembrar que o diminutivo/aumentativo pode ter valores discursivos de **afetividade** e de **depreciação irônica.**

**Ex.:**

|                                                     |
| --------------------------------------------------- |
| **O bonitão vai sair da frente ou não? (deboche)**  |
| **A Ferrari é um carrão! (afetividade, admiração)** |

Por sua vez, o **plural do diminutivo** se faz apenas com o **acréscimo** de **"ZINHOS"** ao plural da palavra, **cortando- se o /S/.**

**Veja:**

|                          |
| ------------------------ |
| **flores = florezinhas** |
| **papéis = papeizinhos** |
| **pás = pazinhas**       |

**<span style="color:#fb4934"><u>Obs.:</u></span>** Em alguns casos, são **aceitas como corretas duas formas**. É o caso de:

|                               |
| ----------------------------- |
| **colherzinha OU colherinha** |
| **florzinha OU florinha**     |
| **pastorzinho OU pastorinho** |

Além disso, o grau pode ser **analítico** (com uso de palavras como "muito grande", "bem pequeno") e **sintético** (com o sufixo "-ão", "-zinho", etc.).

### **1.1.3 Papel sintático dos substantivos:**

A partir de agora, veremos como a **“classe”** da palavra e a **“função sintática”** se comunicam.

Para **identificar o substantivo**, é necessário entender que, quando houver uma função sintática **nominal** (centrada em um **nome**), como sujeito, objeto, adjunto adnominal e complemento nominal, **o substantivo será normalmente o núcleo dessa função**, o elemento central e principal, e será modificado por termos que ficam “em volta”, como artigos, numerais, adjetivos e pronomes.

**Ex.:**

|                                                                                    |
| ---------------------------------------------------------------------------------- |
| **As mulheres do Rio de Janeiro são mais coradas. (mulheres = núcleo do sujeito)** |
| **Estudamos muitas matérias num único dia. (matérias = núcleo do objeto direto)**  |

## **1.2. ADJETIVOS**

**<u>Adjetivo</u>**: é uma classe de palavra **<u>variável</u>** que tem como função **<u>caracterizar ou atribuir qualidades aos substantivos</u>**, indicando **características,** **estados,** **qualidades** ou **condições** dos seres ou objetos a que se referem. Os adjetivos concordam em número (singular ou plural) e gênero (masculino ou feminino) com os substantivos que acompanham.

Existem diferentes tipos de adjetivos, incluindo:

| **Simples**                          | **Composto**                                                                                                                                                                                                                                               | **Primitivo**                                                                       | **Derivado**                                                                                                                                                                                | **Explicativo**                                                                                                                                                                                                                   | **Restritivo**                                                                                                                                                                                                              | **Gentílico**               | **Pátrio**                                                |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | --------------------------------------------------------- |
| **é formado por apenas uma palavra** | é formado pela união de duas ou mais palavras que funcionam como adjetivo, seja por meio de hífen ou não. Geralmente, a primeira palavra modifica ou qualifica a segunda. Por exemplo: "verde-escuro", "bem-intencionado", "azul-marinho", "alto-falante". | palavra que dá origem a outros adjetivos. É aquele que não deriva de outra palavra. | é aquele que deriva de outra palavra, como de um substantivo, de um verbo ou de um outro adjetivo, pelo processo de derivação. Esse processo pode envolver a adição de prefixos ou sufixos. | é opcional na frase e não altera o sentido do substantivo ao qual se refere. Fornece uma informação adicional que não é essencial para identificar o substantivo. Em geral, os adjetivos explicativos são separados por vírgulas. | é essencial para identificar o substantivo ao qual se refere. Ele limita ou restringe o significado do substantivo, fornecendo uma informação necessária para a compreensão completa do termo. Não é separado por vírgulas. | referem-se a povos e raças. | referem-se à origem ou à nacionalidade de algo ou alguém. |

### **1.2.1 Flexão dos adjetivos compostos**:

Em **regra,** no plural dos adjetivos compostos, <u>o primeiro elemento permanece invariável</u> e **<u>apenas o segundo elemento vai para o plural</u>**.

**_Ex.:_** _verde-escuros, alto-falantes._

Entretanto, existem algumas **exceções:**

| **Adjetivo + substantivo**                         | **Adjetivos compostos invariáveis** |
| -------------------------------------------------- | ----------------------------------- |
| nesse caso, ambas as partes ficam no singular.<br> | nunca variam.<br>                   |

### **1.2.2 Valor objetivos (fato) x Valor subjetivos (opinião)**

| **<u>Valor objetivo</u>**<br>                                       | **<u>Valor subjetivo</u>**<br>                                                                               |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| atestam qualidade que é fato, que não depende de interpretação.<br> | expressam uma opinião, são acessórios, podendo ser retirados da frase sem acarretar prejuízo gramatical.<br> |
| **_Ex.:_** _bolsa amarela._<br>                                     | _**Ex**.: menina agitada._<br>                                                                               |
### **1.2.3 Papel sintático dos adjetivos**

A partir de agora, veremos como a **“classe”** da palavra e a **“função sintática”** se comunicam.

 Por seu sentido **qualificador,** ligando-se aos substantivos, o adjetivo pode ter duas funções sintáticas:

| **Predicativo**<br>       | **Adjunto adnominal**<br>    |
| ------------------------- | ---------------------------- |
| **A menina é linda.**<br> | A menina **linda** saiu.<br> |

Será **<span style="color:#83a598">adjunto adnominal</span>** quando estiver **<span style="color:#83a598">"junto" ao nome</span>**, o que sintaticamente significa que o adjetivo estará ligado ao substantivo dentro da mesma expressão, do mesmo "sintagma nominal". 

Será **<span style="color:#fb4934">predicativo</span>** quando **<span style="color:#fb4934">não estiver "junto" ao nome</span>**, estará fora da expressão, fora do sintagma nominal, do termo sintático. Geralmente, vai vir com um **<span style="color:#fb4934">verbo de ligação.</span>** 
### **1.2.4 Ordem da expressão nominal "substantivo + adjetivo"**

É importante saber que a ordem do adjetivo numa frase pode ser capaz de modificar o sentido dele. Assim, o adjetivo pode aparecer antes ou depois de um substantivo e, consequentemente, possuir outro significado.

### **1.2.5 Locuções Adjetivas**

São expressões formadas por **<u>duas ou mais palavras</u>** que desempenham a função de um adjetivo. Elas costumam ser utilizadas para transmitir um significado mais específico a um termo.

Em geral, as **locuções adjetivas** exercem a função sintática de **adjunto adnominal**. O que você precisa saber, nesse momento, é que o adjunto adnominal compreende uma ideia **ativa,** **de posse**.

As bancas tentam confundir o candidato trazendo expressões que parecem locuções adjetivas, mas que possuem **valor substantivo:** é o caso do **complemento nominal**. Nele, a ideia é **passiva.**

- Substantivo abstrato derivado de ação, o termo seguinte, iniciado pela  preposição “de” e com sentido passivo, não será uma locução adjetiva, será um complemento nominal.  

Veja como diferenciá-los:

| **Amor de mãe**<br>                                                                                      | **Leitura do livro**<br>                                                                                          |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **ideia ativa, pois a mãe possui o amor, ela detém a posse dele. Por isso, é um adjunto adnominal.**<br> | ideia **passiva,** pois o livro foi lido, sofreu a ação de ter sido lido. Logo, é um **complemento nominal**.<br> |

### **1.2.6 Grau dos adjetivos**

- **<span style="color:#fe8019">Grau Comparativo</span>**: **é usado para fazer comparações entre duas coisas ou pessoas.**

Existem **três** formas de comparativo:

| **Comparativo de Igualdade**<br>            | **Comparativo de Superioridade**<br>    | **Comparativo de Inferioridade**<br>     |
| ------------------------------------------- | --------------------------------------- | ---------------------------------------- |
| **usa-se "tão... quanto".**<br>             | usa-se "**mais... que**".<br>           | usa-se "**menos... que**".<br>           |
| **_Ex.:_** _Ele é tão alto quanto ela._<br> | _**Ex**.: Ele é mais alto que ela._<br> | _**Ex**.: Ele é menos alto que ela._<br> |

- **<span style="color:#fe8019">Grau Superlativo</span>**: **é usado para indicar o mais alto grau de uma qualidade em relação a um grupo de seres ou coisas.**

Existem **duas** formas de superlativo: 

| **Superlativo Relativo**<br>                                 | **Superlativo Absoluto**<br>                                                                                                                                                                                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Indica uma comparação dentro de um grupo específico.**<br> | Indica o **mais alto grau** de uma qualidade sem fazer comparações.<br>                                                                                                                                                                          |
| **_Ex.: Ele é o mais alto da turma._**<br>                   | Pode ser **absoluto sintético,** quando se acrescenta um sufixo ao adjetivo. _**Ex.:** altíssimo._<br><br>Pode ser **absoluto analítico,** quando se usa palavras como "muito" ou "extremamente" antes do adjetivo. _**Ex.:** Ele é muito alto._ |

## **1.3 ADVÉRBIO**:

**<u>Advérbio</u>**: é uma classe de palavras que **<span style="color:#b8bb26">modifica, complementa ou intensifica</span>** o significado de um **<u>verbo</u>,** **<u>adjetivo</u>,** outro **<u>advérbio</u>.** 

**Advérbio é palavra <u>invariável</u>**, ou seja, **nunca vai para o plural**.

Os advérbios podem ser classificados em várias categorias, dependendo da função que desempenham na frase. Algumas delas são:

|                 |                                                                                          |
| --------------- | ---------------------------------------------------------------------------------------- |
| **Tempo**       | **Ex.: hoje, ontem, agora, depois, sempre (mas também pode indicar frequência), nunca.** |
| **Lugar**       | **Ex**.: aqui, lá, acima, abaixo, dentro, fora, em cima, embaixo.                        |
| **Modo**        | **Ex**.: rapidamente, calmamente, bem, mal, cuidadosamente, amorosamente.                |
| **Intensidade** | **Ex**.: muito, pouco, bastante, extremamente.                                           |
| **Afirmação**   | **Ex**.: sim, certamente, realmente.                                                     |
| **Dúvida**      | **Ex**.: talvez, possivelmente, provavelmente, eventualmente.                            |

**Advérbios Interrogativos:**

|           |                          |
| --------- | ------------------------ |
| **Tempo** | **Ex.:** Quando chegou?  |
| **Modo**  | **Ex**.: Como falou?     |
| **Lugar** | **Ex**.: Onde vive?      |
| **Causa** | **Ex**.: Por que mentiu? |
| **Preço** | **Ex**.: Quanto custou?  |

## **1.4 ARTIGO**:

**<u>Artigo</u>**: é uma classe de palavras que **<span style="color:#b8bb26">acompanha o substantivo</span>** para determiná-lo de maneira **específica** ou **geral,** indicando o gênero (masculino ou feminino) e o número (singular ou plural). Existem dois tipos de artigos: **<span style="color:#b8bb26">definidos</span>** e **<span style="color:#b8bb26">indefinidos</span>.**

|                         |                                                                                                |                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **Artigos Definidos**   | São usados para se referir a algo ou a alguém de maneira **específica**. **(o,a,os,as)**       | **Ex.:** "o carro", "a casa", "os meninos", "as meninas".       |
| **Artigos Indefinidos** | São usados para se referir a algo de maneira **não específica ou genérica**. (um,uma,uns,umas) | **Ex**.: "um livro", "uma cadeira", "uns alunos", "umas mesas". |

Os artigos desempenham um papel fundamental, pois ajudam a **determinar o significado e a função dos substantivos** dentro de uma frase. Eles **concordam em gênero e número** com os substantivos que modificam.

## **1.5 NUMERAL:**

São usados para expressar **<span style="color:#b8bb26">números, quantidades, ordens, proporções e outros conceitos relacionados à numeração.</span>**

Podem ser classificados como:

|                     |                                                 |                                               |
| ------------------- | ----------------------------------------------- | --------------------------------------------- |
| **Cardinais**       | representam **números exatos ou quantidades**   | **Ex**.: um, dois, três, quatro.              |
| **Ordinais**        | indicam a **posição** ou ordem em uma sequência | **Ex**.: primeiro, segundo, terceiro, quarto. |
| **Fracionários**    | expressam **partes** de um todo                 | **Ex**.: meio, terço, quarto.                 |
| **Multiplicativos** | indicam **múltiplos** de um número              | **Ex**.: dobro, triplo, quádruplo.            |

## **1.6 INTERJEIÇÃO:**

São utilizadas para expressar **<span style="color:#b8bb26">emoções</span>,** **<span style="color:#b8bb26">sentimentos</span>,** **<span style="color:#b8bb26">sensações</span>** ou **<span style="color:#b8bb26">estados de espírito</span>**. Podem transmitir surpresa, alegria, dor, alívio, pena... A ideia é que comuniquem emoções e reações imediatas.

As interjeições podem ser **palavras isoladas** ou **frases curtas.** Geralmente, são <u>seguidas por um ponto de </u>**<span style="color:#b8bb26"><u>exclamação</u></span>** para denotar sua natureza expressiva.

Vejamos alguns exemplos de interjeições:

- **Ah!**
- **Oh!**
- **Uau!**
- **Eita!**
- **Ai!**
- **Opa!**

**<span style="color:#fb4934"><u>Atenção</u></span>**: As interjeições se diferem de outras classes de palavras, principalmente, porque **não possuem função sintática específica** na estrutura da frase. 

## **1.7 PALAVRAS ESPECIAIS:**

Algumas palavras podem **apresentar <span style="color:#b8bb26">mais de uma classe de palavras</span>**, a depender do **contexto** em que estão inseridas e do **sentido** que expressam.

Atenção para algumas delas:

### O, A, OS, AS

| **Artigo definido**       | **Ex.: A** menina é feliz.                                      |
| ------------------------- | --------------------------------------------------------------- |
| **Substantivo**           | **Ex**.: O a é uma vogal importante.                            |
| **Pronome oblíquo átono** | **Ex**.: Ela o admira bastante!                                 |
| **Pronome demonstrativo** | **Ex**.: Entre as meninas, conversei com **a** de cabelo preto. |
| **Preposição**            | **Ex**.: Entreguei o envelope **a** ela.                        |

### SÓ

| **Advérbio**           | **Ex.:** Ela **somente** come legumes (advérbio de exclusão / restrição). |
| ---------------------- | ------------------------------------------------------------------------- |
| **Palavra denotativa** | Ex.: **Só** você não quer sair.                                           |
| **Adjetivo**           | Ex.: Ela está **só**.                                                     |

### ATÉ

| **Preposição**         | **Ex.:** Vamos **até** a igreja.                               |
| ---------------------- | -------------------------------------------------------------- |
| **Palavra denotativa** | **Ex**.: **Até** a criança estava sorrindo.                    |
| **Advérbio**           | **Ex**.: Ele **até** veio falar comigo (advérbio de inclusão). |

### AINDA

| **ideia de tempo**                      | **Ex.:** Você **ainda** não saiu de casa.                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------- |
| **ênfase**                              | **Ex**.: Ele **ainda** não desistiu do seu sonho.                                     |
| **ideia de adição (= além disso):**     | **Ex**.: A festa foi incrível, e **ainda** ganhamos doces na saída.                   |
| **ideia de ressalva (= ao menos):**     | **Ex**.: Ela é muito preguiçosa, se **ainda** fosse dedicada, teria ganhado o prêmio. |
| **ideia de oposição (= apesar disso):** | **Ex**.: Ele só a decepciona e você **ainda** o perdoa.                               |

### MESMO

| **pronome demonstrativo** | **Ex.:** Eu **mesma** (= própria) dirigi o carro. / Somos da **mesma** (= especificidade) turma. |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| **palavra denotativa**    | **Ex**.: Todos saíram, **mesmo** a filha (= inclusive).                                          |
| **advérbio de afirmação** | **Ex**.: Ele estuda **mesmo**! (= realmente).                                                    |
| **preposição acidental**  | **Ex**.: Ele deu conselho, **mesmo** sem ter sido solicitado (=embora).                          |
| **locução concessiva:**   | **Ex**.: **Mesmo** que eu não entenda, vou confiar em Deus (=embora, ainda que).                 |

## **1.8 PRONOME**

**Pronomes** são palavras que substituem ou acompanham os nomes, indicando as pessoas do discurso, posses, dúvidas, quantidades, entre outras relações. 

Na substituição, a ideia é evitar que se repita o termo já mencionado. 

Os pronomes podem ser: **<span style="color:#b8bb26">substantivos</span>** ou **<span style="color:#b8bb26">adjetivos</span>.**

Quando os pronomes **substituem** um termo, são chamados de **substantivos.** Por sua vez, quando o **acompanham,** são chamados de **adjetivos.**

Os pronomes podem indicar:

- **<span style="color:#b8bb26">pessoas</span>**
- **<span style="color:#b8bb26">relações de posse</span>**
- **<span style="color:#b8bb26">indefinição</span>**
- **<span style="color:#b8bb26">quantidade</span>**
- **<span style="color:#b8bb26">familiaridade</span>**
- **<span style="color:#b8bb26">localização no tempo</span>**
- **<span style="color:#b8bb26">localização no espaço</span>**
- **<span style="color:#b8bb26">localização no texto</span>**

### **1.8.1 PRONOMES INTERROGATIVOS**

Pronome interrogativo é aquele que introduz uma pergunta direta ou indireta, substituindo ou acompanhando o substantivo sobre o qual se quer obter informação. São usados para frases interrogativas **<span style="color:#83a598">diretas</span>** (com ponto de interrogação) ou **<span style="color:#83a598">indiretas</span>** (sem ponto de interrogação, mas com ideia de pergunta, de questionamento).

**São eles:** 

|            |
| ---------- |
| **Que**    |
| **Quem**   |
| **Qual**   |
| **Quanto** |

**Ex.:**

|                            |
| -------------------------- |
| **Quem chegou?**           |
| **Qual é seu nome?**       |
| **Não sei que horas são.** |

### **1.8.2 PRONOMES INDEFINIDOS:**

**Pronome indefinido** é aquele que se refere à terceira pessoa do discurso de forma **<span style="color:#b8bb26">vaga, imprecisa ou indeterminada</span>**, tanto no que diz respeito à identidade quanto à quantidade.

**São eles:**

**NINGUÉM - NENHUM - ALGUÉM - ALGUM - ALGO - TODO - OUTRO**

**TANTO - QUANTO - MUITO - BASTANTE - CERTO - CADA - VÁRIOS**

**QUALQUER - TUDO - QUAL - OUTREM - NADA - MENOS - QUE - QUEM**

**UM (QUANDO EM PAR COM "OUTRO")**

**Ex.:**

|                               |
| ----------------------------- |
| **Alguém bateu na porta**     |
| **Nada foi resolvido**        |
| **Todos chegaram cedo**       |
| **Algumas pessoas discordam** |
| **Cada um fez sua parte**     |

#### **1.8.2.1 Locuções pronominais indefinidas**

Nada mais são do que pronomes indefinidos compostos por **<span style="color:#b8bb26">mais de uma palavra.</span>**

**São elas:**

|                        |
| ---------------------- |
| **Qualquer um**        |
| **Cada um**            |
| **Alguma coisa**       |
| **Quem quer que seja** |
| **Todo mundo**         |
| **Nem um nem outro**   |

### **1.8.3 PRONOMES POSSESSIVOS:**

São usados para indicar **<span style="color:#b8bb26">posse</span>** ou **<span style="color:#b8bb26">pertencimento</span>.** Concordam em pessoa, gênero e número com o termo a que se referem.

**São eles:**

|        |                                       |
| ------ | ------------------------------------- |
| **1ª** | meu(s), minha(s), nosso (s) nossa (s) |
| **2ª** | teu(s), tua(s), vosso(s), vossa(s)    |
| **3ª** | seu(s), sua(s)                        |

**Ex.:**

|                                      |
| ------------------------------------ |
| **Minha** casa é a mais alta da rua. |
| "Venha a nós o **vosso** reino".     |

### **1.8.4 PRONOMES DEMONSTRATIVOS:**

São usados para indicar a **<span style="color:#b8bb26">posição</span>** ou a **<span style="color:#b8bb26">distância</span>** de algo em relação ao falante, ao interlocutor ou a algo que já foi dito anteriormente.

![[1. Artigo, substantivo, adjetivo, adv, pronome, numeral e interjeição-1.png]]

#### **1.8.4.1 Função Textual do Pronome**:

##### **1.8.4.1.1 Dentro do texto**:

|                     |                                                    |
| ------------------- | -------------------------------------------------- |
| **<u>Anáfora</u>**  | quando o pronome retoma algo já mencionado antes.  |
| **<u>Catáfora</u>** | quando o pronome anuncia algo que ainda será dito. |

**_<span style="color:#fb4934"><u>BIZU:</u></span>_** _**An**áfora, **An**tes._

##### **1.8.4.1.2 Fora do texto**:

|                              |                                                                                   |                                                      |
| ---------------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------- |
| **<u>Dêitica/Exofórico</u>** | **quando os pronomes se referem a elementos fora do texto, como tempo e espaço.** | **Ex.:** Neste país, a desigualdade social é grande. |

**Obs.:** O pronome demonstrativo, com função exofórica, pode indicar localização no **tempo**, no **<span style="color:#b8bb26">espaço</span>** e no **<span style="color:#b8bb26">texto</span>**:

**Tempo**: 

|                                                                  |                                                                        |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **este, esta, isto: indicam tempo presente**                     | **_Ex.:_** Este está sendo um sábado de sol.                           |
| **esse, essa, isso: indicam passado recente ou futuro próximo** | _**Ex**.: Esses dias senti muita dor de cabeça (**passado recente**)._ |
| **aquele, aquela, aquilo: indicam passado ou futuro distante**   | **Ex**.: Aqueles anos 80 foram os melhores da minha vida.              |

 **Espaço**:

|                                                                                      |                                                         |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------- |
| **este, esta, isto: mostram algo que está perto de quem fala**                       | **_Ex.:_** _**Este** doce está maravilhoso!_            |
| **esse, essa, isso: mostram algo que está perto de quem ouve.**                      | _**Ex**.: **Essa** sua roupa é estilosa._               |
| **aquele, aquela, aquilo: mostram algo que está longe de quem fala e de quem ouve.** | _**Ex**.: **Aquele** livro foi escrito há muitos anos._ |

 **Texto**:

|                                                                                                                      |                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **este, esta, isto: indicam algo que ainda será mencionado**                                                         | **_Ex.:_** _**Este** é o meu recado: afaste-se dele._                                                                              |
| **esse, essa, isso: indicam algo que já foi mencionado**                                                             | _**Ex**.: Giovana estudou muito. **Essa** aluna é a melhor da classe!_                                                             |
| **aquele, aquela, aquilo: indicam o antecedente mais distante, enquanto este se refere ao antecedente mais próximo** | _**Ex**.: Pedro e Marcos são irmãos. **Este** trabalhador, **aquele** preguiçoso. (Marcos é o trabalhador e Pedro, o preguiçoso)._ |

### **1.8.5 PRONOMES RELATIVOS:**

São usados para **<span style="color:#b8bb26">conectar duas orações</span>**, referindo-se a um termo **antecedente**, que está presente na oração principal.

Portanto, possuem função **coesiva** (= retomar ou anunciar uma informação) e objetivam evitar a repetição do termo.

**Podem ser: variáveis ou invariáveis.**

#### **1.8.5.1 VARIÁVEIS:**

|                        |
| ---------------------- |
| O qual / os quais      |
| a qual / as quais      |
| Cujo / cuja            |
| Quanto(s) / quantas(s) |

 **Ex.:**

|                                      |
| ------------------------------------ |
| Ele é o menino cujo pai é professor. |
| Esta é a casa a qual me referi.      |

#### **1.8.5.2 INVARIÁVEIS:**

|      |
| ---- |
| Que  |
| Quem |
| onde |

 **Ex.:**

|                                          |
| ---------------------------------------- |
| Esta é a menina que cantava lindamente.  |
| Esta é a casa onde morei a vida inteira. |

**<span style="color:#fb4934">Obs.:</span>** Os pronomes relativos introduzem **<span style="color:#b8bb26">orações subordinadas adjetivas.</span>**

|                                        |                       |
| -------------------------------------- | --------------------- |
| **Que**                                | Para pessoas e coisas |
| **Quem**                               | Para pessoas          |
| **O qual, a qual, os quais, as quais** | Para pessoas e coisas |
| **Cujo, cuja, cujos, cujas**           | Para posse            |
| **Onde**                               | Para lugar            |
| **Quando**                             | Para tempo            |

### **1.8.6 PRONOMES DE TRATAMENTOS:**

**Pronome de tratamento** é aquele usado para **se referir respeitosa ou formalmente a alguém**, geralmente em situações de formalidade, autoridade ou cortesia.

**<span style="color:#fb4934">Obs.:</span>** Apesar de se referirem à **segunda pessoa**, esses pronomes exigem a **conjugação verbal na <span style="color:#fb4934">terceira pessoa</span>**.

|                                                    |                                                       |
| -------------------------------------------------- | ----------------------------------------------------- |
| **Pronomes Tratamento**                            | **Uso Principal**                                     |
| **Vossa Excelência - V.Ex. ª / V.Exa. (V.Ex.as):** | Autoridades dos três poderes: juízes, políticos, etc. |
| **Vossa Senhoria - V.S.ª / V.Sa.  <br>(V.S.ªs)**   | Uso formal em comunicações oficiais                   |
| **Vossa Magnificência - V.Mag.a (V. Mag.as)**      | Reitores de universidades                             |
| **Vossa Reverendíssima - V.Rev.ma (V.Rev.mas)**    | Padres                                                |
| **Vossa Eminência - V.Em.a  <br>(V.Em.as):**       | Cardeais da Igreja Católica                           |
| **Vossa Santidade - V.S.**                         | Papa                                                  |
| **Vossa Alteza - V.A. (VV.AA.)**                   | Príncipes e princesas                                 |
| **Vossa Majestade - V.M.  <br>(VV.MM.)**           | Reis e rainhas                                        |
