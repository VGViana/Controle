# Como usar a Wikipedia

Esta pasta é uma **camada de navegação e contextualização** sobre o material original.

### Regra de preservação

As notas originais foram mantidas com seu conteúdo e ordem. Nesta versão, foram apenas **acrescentados blocos de navegação ao final** das notas, sem reescrever ou reorganizar o material existente.

### Como navegar

1. Comece por [[00 - Wikipedia dos Estudos]].
2. Entre no hub da matéria.
3. Use as notas conceituais para entender termos transversais.
4. Volte para a nota original para estudar o conteúdo completo.
5. Use os links `[[...]]` do Obsidian para seguir relações entre matérias.

A pasta `NavegaLei` continua sendo a camada normativa; ela foi preservada.
